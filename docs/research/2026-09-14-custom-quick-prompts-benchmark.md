# 快捷提示语产品调研

## 一、调研结论

快捷提示语设计为输入框内的个人效率工具：用户维护自己的提示语库，通过“分类—提示语”两级结构选择；选中后先插入输入框，允许修改，再由用户主动发送。分类非必填，未填写时归入“未分组”。

它与上下文主动建议不是同一个功能：

| 对比项 | 快捷提示语 | 上下文主动建议 |
|---|---|---|
| 内容来源 | 用户预先创建并维护 | 系统根据最新回答生成 |
| 使用时机 | 发送消息前 | AI 回答完成后 |
| 点击结果 | 插入输入框，可修改 | 直接发送 |
| 数量 | 个人列表，数量上限待定 | 固定三条 |
| 失败影响 | 不影响手动输入 | 不影响主回答 |

## 三、推荐产品流程

    对话输入框 > 快捷提示语
      ├─选择已有提示语 → 插入输入框 → 用户修改或补充 → 主动发送
      └─新建提示语 → 填写名称、可选分类与正文 → 保存 → 返回对应分类 → 选择使用

管理闭环：

    个人提示语列表
      ├─编辑 → 更新名称或正文 → 不影响历史消息
      └─删除 → 二次确认 → 从列表移除 → 不影响已发送消息

## 四、界面建议

| 动作 | 显示 | 类型 | 描述 |
|---|---|---|---|
| 点击输入框入口 | 分类及个人快捷提示语列表 | 浮层 | 按“分类—提示语”展示，提供新建入口及管理操作 |
| 选择分类 | 该分类下的提示语 | 级联菜单 | 未填写分类的内容显示在“未分组”中 |
| 选择一条提示语 | 正文进入当前输入框 | 即时反馈 | 在光标位置插入，可修改，不自动发送 |
| 新建提示语 | 名称、分类和正文 | 弹窗 | 名称和正文必填，分类非必填；通过数量和长度校验后保存 |
| 编辑提示语 | 已保存名称和正文 | 弹窗 | 保存后更新个人列表 |
| 删除提示语 | 删除确认 | 确认弹窗 | 删除个人配置，不处理历史消息 |
| 列表为空 | 空态与新建入口 | 空状态 | 不阻塞手动输入 |
| 加载或保存失败 | 错误原因与重试 | 错误状态 | 保留输入框及表单中已有内容 |

## 五、业务边界

- 快捷提示语默认属于个人数据，不作为组织公共提示库。
- 选择提示语不等于发送消息，不产生模型调用或费用。
- 用户主动发送后，提示语正文与普通输入文字完全一致，沿用现有会话、权限和计费链路。
- 删除或修改提示语不回溯修改历史消息。
- 首期不支持模板变量、自动执行、定时执行和团队分享。
- 每个用户最多创建 100 条；达到上限后只能编辑或删除已有提示语。
- 名称长度为 1～20 个字符，正文长度为 1～10000 个字符。
- 分类非必填，未填写时统一进入“未分组”。

## 六、已确认参数

| 参数 | 规则 |
|---|---|
| 分类 | 非必填；未填写时归入“未分组” |
| 单用户数量上限 | 100 条 |
| 名称长度 | 1～20 个字符 |
| 正文长度 | 1～10000 个字符 |
| 默认排序 | 分类内按最近更新时间倒序 |

## 七、验收关注点

1. 入口位于输入框工具区，不需要离开当前会话。
2. 新建、编辑、删除和选择使用形成完整闭环。
3. 选中后只插入输入框，不自动发送，可继续修改。
4. 用户无法查看或操作其他人的个人提示语。
5. 空态和异常不影响正常手动输入与发送。
6. 达到数量或长度上限时不能保存，并显示具体限制。
