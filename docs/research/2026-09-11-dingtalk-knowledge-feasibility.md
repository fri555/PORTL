# 钉钉知识库打通可行性与产品方案调研

## 一、研究结论

钉钉知识库接入在方向上可行，但当前证据不足以直接承诺“全部知识库、全部文档类型、实时增量、权限完全一致”。建议 V1.2 先对一个指定知识库做企业租户验证，满足正文、附件、权限和删除四个门槛后，再安排 V1.3 生产接入。

用户提供的参考方案进一步证明了“企业内部应用授权—选择钉钉目录—导入并建立来源绑定”的产品路径可落地。天马采用其账号绑定、凭证状态、目录树多选、保留层级和已选数量等交互，但不采用“一次性复制到个人文件空间”的业务语义；天马应将钉钉定义为知识中心外部数据源，首次同步后持续更新。

一期推荐方案：

    超级管理员选择指定知识库
      → 管理员授权企业内部应用
      → 首次同步目录、文档和可取得的附件
      → 进入天马现有知识入库与 RAG
      → 每天 00:00 做全量对账式增量检查
      → 管理员可修改时间或手动立即同步
      → 事件订阅只用于加速，不作为唯一更新来源

## 二、已经确认的官方能力

钉钉开放平台提供知识库开放能力，官方知识库概述列出了知识库管理和知识库文档相关接口。[^1]

钉钉开放平台的权限模型分为：

- 委托权限：应用代表当前用户访问，应用不能读取用户本身无权访问的资源。
- 应用权限：应用以自身身份访问组织范围数据，必须由组织管理员授权，且平台管控更严格。[^2][^3]

钉钉支持 HTTP、Stream 等事件订阅方式。Stream 使用 WebSocket 接收事件，事件带消息 ID，消费方需要返回确认；未正确确认可能出现重复推送，因此接入方仍需幂等处理。[^4][^5]

钉钉开发须知要求调用前配置接口权限、了解频率限制，并推荐配置事件订阅。[^6]

## 三、尚未被公开证据充分确认的能力

以下事项必须在天马企业测试租户中逐项验证，不能仅根据“有知识库 API”就视为全部支持：

1. 所有目标文档类型能否取得完整正文。
2. 富文本、表格、智能文档、内嵌数据表能否保留结构。
3. 文档附件能否枚举、下载和判断权限。
4. 目录节点是否提供稳定 ID、修改时间或修订号。
5. 是否存在覆盖知识库文档新增、修改、删除的事件。
6. 是否存在成员、节点或空间权限变化事件。
7. 应用权限能否读取全部目标知识库，是否还受空间白名单或成员身份限制。
8. 删除或失权后，接口是返回不存在、无权限，还是仍返回历史元数据。

调研发现钉钉支持通用事件订阅，但公开事件示例主要覆盖通讯录、群、审批、日程等业务，无法据此证明知识库的内容和权限事件完整覆盖。[^4] 因此首期不能设计成纯事件实时同步。

## 四、接入全部知识库还是指定知识库

### 方案 A：只接指定知识库

管理员在天马选择允许同步的知识库。

优点：

- 权限范围清晰；
- 试点数据量和风险可控；
- 可以逐库验证内容质量和同步耗时；
- 发生误同步时影响范围较小；
- 更符合最小权限原则。

缺点：

- 新知识库需要管理员再次配置；
- 不能自动覆盖企业所有知识。

结论：一期推荐。

### 方案 B：接入全部可见知识库

应用按企业级权限枚举并同步全部知识库。

优点：

- 覆盖面大；
- 新知识库可自动进入同步范围。

缺点：

- 很可能需要高权限应用授权；
- 容易同步不应进入天马的敏感资料；
- 数据量、附件量和限流压力难预估；
- 权限变化和责任边界复杂；
- 内容质量问题会在多个知识库同时放大。

结论：不建议作为首期默认方案。后续即使支持，也应采用“发现全部、管理员逐库启用”，而不是授权后自动导入全部。

## 五、权限方案比较

### 委托访问

应用代表用户读取其可见内容。优点是权限天然贴近钉钉；缺点是后台定时同步需要长期用户授权，并且不同用户能看到的集合不同，难以构建一次同步、多用户复用的企业知识索引。

适用场景：用户临时打开或检索钉钉文件，不适合单独承担企业级离线同步。

### 应用访问加 ACL 同步

企业管理员授予应用读取指定范围内容，天马同步内容和访问控制信息，查询时再按用户过滤。

优点：适合后台定时同步和统一索引。

缺点：应用权限范围大；如果钉钉不能提供足够完整的节点成员和权限信息，天马无法准确复刻可见性。

适用场景：生产知识接入的候选方案，但必须先通过 ACL 验证。

### 推荐

使用企业内部应用读取明确选择的知识库，同时同步空间、节点和成员权限。若某类文档无法取得可靠 ACL，则不将该类文档纳入生产同步，不能先同步后默认全员可见。

## 六、同步与抽取流程

### 首次同步

    管理员选择知识库并授权
      → 读取知识库基本信息
      → 读取目录树
      → 逐节点读取正文、附件和权限
      → 记录来源 ID 与修订信息
      → 进入天马现有解析、切片和向量化
      → 显示完成数量、失败数量和最后同步时间

### 日常同步

默认每天北京时间 00:00 执行。管理员可以按数据源修改同步时间，也可以手动立即同步。

    获取本次目录与节点集合
      → 与上次来源集合比较
      ├─新增：下载并抽取
      ├─修订号、修改时间或内容哈希变化：重新下载并抽取
      ├─上次存在、本次不存在：进入删除或失权确认
      ├─ACL 变化：更新可见范围
      └─无变化：不重复抽取

如果官方提供可用文档事件，事件到达后立即处理对应节点；每天 00:00 的对账仍保留，用于补偿漏事件和权限漂移。

### 失败

- 单节点失败不阻塞其他节点同步。
- 初次失败后自动重试 2 次。
- 三次均失败后显示节点、原因和手动重试。
- 认证失效、知识库授权取消等整体错误停止本次同步，并提示管理员重新授权。
- 同一同步事件重复到达不能重复创建知识文件。

## 七、删除、修改和权限取消

### 删除

发现钉钉文档删除后，天马来源立即标记失效，不物理删除历史记录。对应内容停止出现在知识列表、搜索、RAG 和未来知识图谱中。

### 修改

先保留旧知识结果并标记“可能已过期”，新版本同步和抽取成功后再切换。新版本失败时管理员仍能看到旧结果状态和失败原因。

### 权限取消

权限取消应比重新抽取优先。确认用户或系统不再有权访问时，立即从其可见范围中排除，不等待下一次内容解析。

### 区分删除与暂时无权

两者对用户都要立即不可见，但管理审计中必须区分：

- 来源已删除；
- 企业应用失去权限；
- 当前用户失去权限；
- 知识库整体取消授权；
- 接口临时失败，尚不能确认状态。

接口临时失败不能直接把全部内容判断为已删除。只有明确删除事件，或连续对账确认来源不存在时，才执行来源删除失效。

## 八、与天马现有知识中心的关系

钉钉只是新增一种外部数据源，不新建一套搜索或问答能力。

    钉钉原始文档
      → 外部来源记录
      → 现有知识解析与向量化
      → 现有 RAG
      → 未来可触发知识图谱抽取

每条知识应保留：

- 钉钉企业；
- 知识库；
- 目录路径；
- 节点 ID；
- 文档类型；
- 原文链接；
- 修订或内容摘要；
- 最后同步时间；
- 当前有效状态；
- 当前权限范围。

## 九、主要风险

| 风险 | 后果 | 决策 |
|---|---|---|
| 正文接口不能覆盖所有文档类型 | 同步内容残缺 | 首期只接验证通过的类型 |
| 附件无法稳定下载 | 知识不完整 | 附件能力单独列验收项 |
| 文档和权限事件不完整 | 实时同步会漏数据 | 每日对账为主，事件为辅 |
| 应用权限过大 | 数据泄露风险 | 指定知识库、最小权限、审计 |
| 逐用户委托授权 | 后台同步复杂且易失效 | 不作为企业离线同步主方案 |
| 限流与大知识库 | 首次同步时间不可控 | 分批、断点续传、退避和补跑 |
| 临时接口错误被误判为删除 | 大量内容错误失效 | 区分不存在、无权和临时错误 |

## 十、V1.2 验证清单

选取一个非敏感测试知识库，至少包含：

- 两级目录；
- 普通文档；
- 表格或结构化文档；
- 带附件文档；
- 两组不同成员权限；
- 一篇可修改和删除的测试文档。

依次验证：

1. 枚举知识库与目录。
2. 读取各类正文。
3. 枚举并下载附件。
4. 获取节点与知识库权限。
5. 修改正文并检测变化。
6. 移动目录并保持来源身份。
7. 删除文档并检测失效。
8. 撤销用户权限并停止检索。
9. 撤销应用或知识库授权并停止同步。
10. 重复事件和重复同步不产生重复数据。

只要正文、ACL、删除三项中任意一项无法可靠完成，就不进入生产开发。

## 十一、投入与版本建议

| 范围 | 估算 |
|---|---:|
| 一个知识库的能力验证 | 8–15 人日 |
| 指定知识库生产接入 | 25–45 人日 |
| 扩展全部知识库、复杂 ACL 和更多文档类型 | 45–70 人日 |

建议：

- V1.1.0：保留调研结果。
- V1.2：验证一个指定知识库。
- V1.3：验证门槛全部通过后，先上线“管理员选择知识库”，不默认同步全企业。

### 推荐界面流程

    知识中心 > 添加数据源 > 钉钉知识库
      → 凭证授权
      → 选择钉钉知识库 / 文件夹 / 文档
      → 选择天马保存位置
      → 设置同步时间并确认范围
      → 首次同步
      → 数据源详情查看状态、统计、失败原因和手动同步

| 动作 | 显示 | 类型 | 描述 |
|---|---|---|---|
| 新增/更换凭证 | 授权状态、应用名称、最近校验时间 | 弹窗 | 密钥提交后不再明文展示；更换时重新校验已选范围 |
| 展开目录 | 知识库、文件夹、文档层级 | 树形选择器 | 支持复选；不可读取或不支持的节点禁用并说明原因 |
| 勾选父级 | 已选项目数与范围摘要 | 实时反馈 | 递归包含受支持节点；父子重复选择只保留一份来源 |
| 选择保存位置 | 天马知识库及目录 | 级联选择器 | 结果进入现有知识中心，不默认进入个人文件空间 |
| 确认接入 | 首次同步任务 | 主按钮 | 凭证、来源、保存位置完整时才可提交 |
| 查看同步详情 | 新增、更新、失效、跳过、失败数量 | 详情页 | 同时显示最近和下次同步时间、失败明细及手动重试 |

天马可借鉴钉钉 AI 助理的“选择来源—查看学习进度—预览效果”，但入口应放在天马知识中心的“添加数据源”中，而不是智能体编辑页。同步详情至少展示来源知识库、授权状态、最近同步时间、下次同步时间、同步范围、新增/更新/失效/跳过/失败数量和手动同步入口。
