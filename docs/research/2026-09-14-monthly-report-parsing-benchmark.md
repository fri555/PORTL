# 特殊文档解析产品调研

## 一、结论

V1.1.0 不再让用户选择“月报解析”，改为系统自动分流：先区分本地文件与在线文档，再对本地文件按真实格式选择解析链路。

- 本地 Excel：统一使用结构保留解析，经营月报与普通表格不再区分。
- 本地 PPT/PPTX：先转为 PDF，再进行 PDF 版面解析。
- 本地 PDF：直接进行 PDF 版面解析。
- 在线文档：按来源平台和节点类型进入现有授权、同步与内容获取链路，不按文件名后缀判断。

该方案废弃解析勾选框和 `[tmyb]` 等特殊文件名规则。系统只判断技术格式，不判断 Excel 在业务上是否属于月报。

## 三、为什么按来源和格式自动分流

1. 文件格式可通过文件内容、MIME 和后缀综合识别，不需要用户理解解析器。
2. Excel 月报与普通表格都需要保留工作表、表头和行列关系，没有必要再按业务语义分类。
3. PPT/PPTX 可以统一转换成 PDF，复用成熟的版面解析能力。
4. 在线文档是平台节点，不等同于本地文件；其授权、同步、正文获取和失效规则必须独立处理。
5. 文件名和人工勾选容易误选、漏选，新增格式后还会持续增加用户认知成本。

## 四、处理流程

    内容进入知识中心
      → 判断来源类型
          ├─本地文件 → 校验真实格式
          │              ├─Excel → 结构保留解析
          │              ├─PPT/PPTX → 转 PDF → PDF 版面解析
          │              ├─PDF → PDF 版面解析
          │              └─其他格式 → 现有解析链路
          └─在线文档 → 来源授权与内容获取 → 在线文档解析
      → 现有知识切片、向量化、检索和 RAG

在线文档名称即使带 `.pptx` 或 `.xlsx`，仍按在线节点处理；只有导出或下载后重新上传，才按本地文件格式处理。

## 五、解析要求

### Excel

- 保留工作簿、工作表、标题、说明文字和表格顺序。
- 保留表头、行列关系、单元格显示值和合并单元格形成的层级。
- 知识片段可追溯到原文件、工作表和区域。
- 不判断是否为经营月报，不强制抽取固定财务字段。

### PPT/PPTX

- 转换后的 PDF 仅作内部中间文件，不在知识中心重复展示。
- 保留原 PPT 文件名、幻灯片页码、PDF 页码和知识片段的对应关系。
- 提取每页可见文字、图片说明、表格和版面顺序。
- 动画、切换效果、嵌入音视频和演讲者备注不属于本期保证范围。

## 六、状态与异常

统一状态为：格式识别中、转换中、解析中、自动重试中、已完成、处理失败。

- 后缀与真实格式不一致时，以真实格式为准。
- 文件损坏、加密或格式无法识别时，明确提示失败原因。
- 转换或解析失败自动重试 2 次，仍失败后支持手动重试。
- 手动重试复用同一文件记录，不产生重复文件。
- 失败不得静默回退普通文本解析。
- 在线文档授权失效按在线来源异常处理，不转成本地文件解析。

## 七、V1.1.0 决策

1. 需求名称调整为“特殊文档解析”。
2. 不设置月报、PPT 或 PDF 解析勾选框。
3. 本地文件按真实格式自动路由，在线文档按来源节点类型处理。
4. 所有 Excel 使用结构保留解析；不识别业务语义上的“月报”。
5. PPT/PPTX 自动转 PDF 后解析，中间文件不面向用户展示。
6. 失败自动重试 2 次，不静默降级。
7. 继续使用现有知识中心和 RAG，不新增平行检索链路。
