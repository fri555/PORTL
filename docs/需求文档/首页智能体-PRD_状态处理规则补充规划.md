## 三、拟写入钉钉的最终草稿

### <span style="color:#FF7D00">状态处理规则</span>

适用场景：模式切换（日常办公 / 专家模式）、智能体切换、功能卡片点击。
管控对象：输入框内容、联网查询开关、已上传文件（含会话内已解析文件、输入区待发送附件）。

**联网查询开关通用规则**：用户手动修改过的开关设置优先保留；从未修改过时，使用目标智能体 / 模式 / 卡片的默认值。默认不开启。

**规则概述（速览表）**

| 管控对象 | 通用处理原则 |
| :--- | :--- |
| 输入框内容 | 跨会话带入保留；功能 / 子能力卡片点击时覆盖写入 |
| 联网查询开关 | 保留用户手动设置；未修改过则用默认值（默认不开启联网） |
| 已上传文件 | 跨会话带入，完整保留不清除 |

| 操作场景 | 输入框内容 | 联网查询开关 | 已上传文件 |
| :--- | :--- | :--- | :--- |
| **1. 日常办公 → 专家模式选择页**（仅打开选择入口，未选定智能体） | 完整保留 | 不变 | 完整保留 |
| **2. 选定或切换智能体**（选择页→选定，或A→B切换） | 完整保留 | 按通用规则（智能体预设 / 保留用户设置） | 完整保留 |
| **3. 切回日常办公模式** | 完整保留 | 按通用规则（恢复日常默认不开启；已改过则保留） | 完整保留 |
| **4. 日常办公，功能卡片** | 覆盖写入 | 普通卡片：不变；强联网卡片：自动开启（已关则不强制，提示建议开启） | 完整保留 |
| **5. 专家模式，子能力卡片** | 覆盖写入 | 按通用规则 | 完整保留 |
| **6. 新对话** | — | 恢复默认（不开启） | — |

> 注：模式切换为跨会话切换（路线X），输入框与文件由系统自动带入目标会话，用户无需重输 / 重传。

#### 例外强制规则（仅特殊场景生效）
仅当智能体 / 卡片具备**合规强制要求**或**核心能力强依赖**时，可突破用户设置，同时必须给出明确醒目提示：
- **强制断网类**（如内网安全、涉密智能体）：切换时强制关闭联网，弹出全局提示「当前为安全模式，已自动禁用联网功能」；切回普通模式时，自动还原用户此前的联网设置。
- **强制联网类**（如实时库存查询、实时行情智能体）：用户关闭联网时禁用发送按钮，明确提示「该智能体核心能力依赖联网，请开启后使用」，不降级输出低质量结果。

#### 核心设计原因

**1. 用户资产主权原则：输入与文件归属会话，不归属于模式**
输入文字、上传文件是用户的劳动成果，归属当前会话而非某个模式或智能体。切换模式 / 智能体本质是"换 AI 的处理角色"，不是"开启新对话"——保留的副作用极低（不需要可手动删除），清空则不可逆，优先选择低风险方案。

**2. 用户设置优先级：手动操作 > 模式默认值**
用户主动点击修改联网开关，属于明确的意图表达，优先级高于任何模式 / 智能体的预设配置。默认值仅覆盖"用户无明确偏好"的场景，不能反向覆盖用户的主动选择，避免"系统自作主张"的失控感。

**3. 心智一致性：符合主流产品交互惯例**
行业内 AI 对话产品均遵循"切角色不丢输入、用户设置不被覆盖"的交互惯例，用户已形成稳定心智。遵循该规则可降低学习成本，避免因怕丢失内容而不敢切换模式。
