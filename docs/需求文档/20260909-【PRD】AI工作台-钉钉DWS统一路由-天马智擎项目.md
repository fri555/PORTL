# 钉钉 DWS 统一路由需求简要

天马智擎需将 `dingtalk-dws` 作为钉钉能力的统一入口：只要用户提到“钉钉”“DingTalk”或“DWS”，即使只是裸关键词，也必须调用该技能；DWS 当前覆盖通讯录、群聊、日历、待办、审批、考勤、DING、日志、AI 表格、文档、钉盘、AI 听记和开发者文档 13 个产品域、159 条命令，可组合完成会议纪要待办执行、数据自动化、群消息、审批和周报等场景。除查询日程、创建日程、创建待办三个场景使用平台已有专用工具外，其余钉钉请求均默认使用 DWS，其中查询待办明确使用 DWS；具体命令与参数以当前版本的 `dws --help` 为准，能力清单未枚举的请求仍应先查帮助，不得直接改用其他钉钉工具或猜测命令。仅有裸关键词而无具体任务时，技能先询问用户需求，不立即登录或执行业务命令。
