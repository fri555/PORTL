### M9-知识库细粒度权限

#### 功能需求描述

将知识中心权限细化至知识库、文件夹和文件三级。上一期已完成知识库层级权限，本期重点对文件夹和文件层级做权限设置。

与M6联动：权限变更后立即更新向量片段权限并清除检索缓存，无查看权限的内容不得出现在检索结果中。  
与M11联动：权限变更后文件树同步更新锁定状态标识。

#### 竞品调研：飞书与钉钉知识库权限机制

| 维度 | 飞书 | 钉钉 |
| --- | --- | --- |
| 权限层级 | 企业→知识库→页面（三级） | 知识库→文件夹→文档（三级） |
| 默认继承 | 子文件夹/文档默认继承上级目录权限 | 子文件夹/文档默认继承上级目录权限 |
| 自定义权限 | 子页面可单独设置权限，但不能超出父级允许范围 | 支持BREAK模式打断继承，单独设置权限 |
| 降低权限 | 父级授予EDITOR时，子页面不能降为READER（需先BREAK继承） | 继承权限高于目标角色时修改不生效，需先BREAK |
| 权限角色 | 管理员/可编辑成员/可阅读成员 | OWNER/MANAGER/EDITOR/DOWNLOADER/READER |
| 黑名单 | 无显式黑名单，通过“移除成员”实现 | 无显式黑名单，通过“删除权限”实现 |

结论与本期方案：

权限设置：参考钉钉做法，管理员可直接为文件夹或文件配置可查看的人员/部门范围。文件夹和文件默认勾选“继承上级”；勾选时，当前生效范围为上级有效权限与本级新增权限的合集，并持续跟随上级变化；取消勾选后停止继承，仅保留本级配置的可查看范围。

权限项：本期仅“可查看”一种权限项，列表中只读展示，不支持切换权限类型。只有管理员可以设置或移除本级直接配置的可查看人员/部门。

授权对象：支持按人员、部门授权（与钉钉开放平台一致）。

#### 用户角色与用户故事

作为一名管理层或资源负责人，我希望公共资料便于继承共享，敏感子目录和文件又能通过取消继承单独收紧权限。

#### 业务主流程图及说明

用户操作 / 系统反馈：

管理员在文件夹或文件的更多菜单中进入权限设置。

系统默认勾选“继承上级”，并在继承成员/部门后展示“来自上级”标签。

管理员可在保持继承的同时新增本级可查看人员/部门；如需完全独立配置，可取消勾选“继承上级”。

保存前展示下级资源影响数量、继承状态和权限变化摘要。

确认后更新有效权限，文件树和右侧列表同步更新锁定状态。

#### 分支流程（异常流程）

授权主体被删除或组织架构变化后，失效主体自动退出有效权限。

勾选“继承上级”时，凡包含“来自上级”身份的成员/部门（包括双重身份）在本级均只读、不可移除；需前往上级资源修改。

取消“继承上级”后若本级没有任何可查看对象，保存时提示“至少保留一个可查看对象”。

并发修改时拒绝覆盖较新的配置，要求刷新后重试。

管理员正在编辑权限设置时被移除了管理员角色，保存操作被拒绝并提示“你已无权限编辑此资源权限”。

删除文件夹时，其下所有子文件夹和文件的权限配置一并删除，不可恢复。

#### 业务规则和约束条件

| 规则项 | 说明 |
| --- | --- |
| 默认继承 | 新建子文件夹和文件默认勾选“继承上级”，沿用直接父节点的当前有效权限 |
| 继承与本级配置 | 勾选继承时，生效范围为上级有效权限与本级可查看范围的合集；本级配置不会自动打断继承 |
| 取消继承 | 取消勾选并保存后，仅本级配置生效，上级后续变化不再影响该节点 |
| 权限来源标签 | 继承对象展示“来自上级”，本级对象展示“直接设置”；已继承对象仍可在本级勾选，形成双重身份；凡包含“来自上级”身份的行均只读且不可移除，纯“直接设置”对象可独立移除 |
| 重复授权 | 同一对象同时来自上级和本级时只展示一行、同时展示两个来源标签且生效一次；双重身份行在本级不可编辑、不可移除 |
| 权限编辑权 | 只有管理员可以设置或移除本级直接配置的可查看人员/部门；不支持修改权限类型 |
| 权限项 | 本期仅“可查看”一种权限项，列表只读展示；下载权限由M8单独控制 |
| 搜索与RAG | 无查看权限内容不得出现在列表、搜索、推荐、引用或模型上下文（与M6联动） |
| 索引权限 | 权限变化后，向量片段权限与检索缓存立即失效（≤5s，N10），不等待重新向量化 |
| 删除清理 | 删除文件时同步停止召回，异步清理切片、向量、缩略图等衍生数据（与M11联动） |
| 并发控制 | 乐观锁机制，并发修改时拒绝覆盖，要求刷新重试 |
| 级联删除 | 删除文件夹时，其下所有子文件夹和文件的权限配置一并删除，不可恢复 |
| 管理员权限回收 | 管理员正在编辑权限时被移除管理员角色，保存操作被拒绝并提示无权限 |
