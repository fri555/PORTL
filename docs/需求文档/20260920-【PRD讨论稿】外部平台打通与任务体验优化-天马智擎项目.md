## 1. 本期范围

| 模块 | 需求 |
| --- | --- |
| M1 | 钉钉知识库打通 |
| M2 | 企业微信打通 |
| M3 | 任务置顶、日期时间展示 |

## 2. M1 钉钉知识库打通

### 2.1 功能需求描述

打通天马智擎与钉钉知识库，使钉钉知识库内容可在天马智擎相关业务中使用。

## 3. M2 企业微信打通

### 3.1 功能需求描述

打通天马智擎与企业微信，使企业微信能力可接入天马智擎相关业务。

## 4. M3 任务置顶、日期时间展示

### 4.1 功能需求描述

- 支持任务置顶。
- 任务页面展示日期时间信息。
