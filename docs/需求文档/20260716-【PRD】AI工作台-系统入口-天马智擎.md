# 2. 产品概述

## 2.1 产品定位

AI 工作台「系统入口」是面向集团员工的统一业务系统导航。它将分散在不同域名、App、小程序和线下获取方式中的系统入口集中呈现，使用户能够按业务分类快速找到目标系统，并通过统一 SSO 完成免登访问。

本功能只负责「发现系统 → 判断可访问性 → 发起访问 → 记录结果」的入口闭环，不承载目标系统内部业务流程。系统入口是工作台中的独立功能模块，不包含常用工作助手、日历、日程、任务或 AI 对话能力。

## 2.2 产品目标

1. **统一入口**：集中管理集团业务系统入口，减少员工查找网址、保存个人书签和反复确认访问方式的成本。
2. **按权展示**：根据用户身份、部门和角色展示可用系统，避免无权限入口造成干扰或越权访问。
3. **一次登录**：已接入 SSO 的系统支持免登跳转，未接入系统明确展示原始登录方式。
4. **个性常用**：用户可将高频系统加入常用或取消常用，并跨设备保留个人偏好。
5. **多形态统一**：网页、App、小程序、待开启系统和后端服务使用统一卡片承载，并采用与入口形态匹配的交互。
6. **可配置运营**：管理员可维护系统信息、分类、权限、状态、排序和 SSO 配置，无需前端发版。

## 2.3 用户角色

| 角色 | 说明 | MVP 范围 |
| --- | --- | --- |
| 普通员工 | 通过门户 SSO 登录，根据权限查看系统入口、加入/取消常用并访问系统 | ✅ 核心角色 |
| 系统入口管理员 | 维护系统目录、业务分类、入口状态、可见范围、排序和 SSO 配置 | ✅ 后台配置角色 |
| 业务系统负责人 | 提供并确认系统名称、网址、使用部门、归属架构、访问方式和 SSO 接入信息 | ✅ 协作角色，不直接操作前台 |
| 安全 / 运维人员 | 管理统一身份认证、目标系统接入与访问审计 | ✅ 支撑角色 |

### 用户故事地图

用户在系统入口中的核心活动主线：**进入工作台 → 查找系统 → 管理常用 → 访问系统 → 处理结果**。

| 用户活动 | 用户任务 | 用户故事 | 优先级 |
| --- | --- | --- | --- |
| **进入工作台** | 身份校验 | 作为员工，我希望系统识别我的登录身份，以便只看到有权使用的系统 | MVP |
| | 加载入口 | 作为员工，我希望进入页面后快速看到常用系统，以便开始工作 | MVP |
| **查找系统** | 切换分类 | 作为员工，我希望按业务分类筛选系统，以便快速缩小查找范围 | MVP |
| | 识别系统 | 作为员工，我希望看到系统名称、使用部门、架构和访问方式，以便确认是否为目标系统 | MVP |
| **管理常用** | 加入常用 | 作为员工，我希望将高频系统加入常用，以便下次更快访问 | MVP |
| | 取消常用 | 作为员工，我希望取消不再常用的系统，以便保持常用区整洁 | MVP |
| | 跨设备同步 | 作为员工，我希望常用状态跟随账号同步，以便更换设备后仍可使用 | MVP |
| **访问系统** | 网页访问 | 作为员工，我希望网页系统在新标签页打开，以便保留工作台页面 | MVP |

| | 查看非网页入口 | 作为员工，我希望系统明确告诉我 App、小程序或安装包的获取方式 | MVP |
| **处理结果** | 获取失败原因 | 作为员工，我希望跳转失败时看到明确原因和处理建议，以便继续工作 | MVP |
| | 重新访问 | 作为员工，我希望网络或凭证异常后可以重试，以便恢复访问 | MVP |
| **维护目录** | 配置系统 | 作为管理员，我希望维护系统信息、权限和状态，以便入口与实际情况保持一致 | MVP |
| | 配置 SSO | 作为管理员，我希望按系统配置免登方式和回调地址，以便逐步完成系统接入 | MVP |

## 2.4 方案对比

### 2.4.1 方案参考

| 方案 | 核心特征 | 优点 | 局限 |
| --- | --- | --- | --- |
| 浏览器收藏夹 | 用户自行保存网址 | 使用简单、无需建设 | 无统一权限、无入口状态、无法集中维护、跨设备与组织管理弱 |
| 静态系统导航页 | 管理员维护固定系统链接 | 集中展示、建设成本较低 | 无个人常用、无按权展示、SSO 与异常处理能力有限 |
| 本方案：统一系统入口 | 系统目录 + 分类 + 个人常用 + 权限 + SSO + 多入口形态 | 形成发现、访问和管理闭环，可持续运营 | 需要逐系统核对数据和推进 SSO 接入 |

### 2.4.2 差异化定位

| 差异化机会 | 常见问题 | 本方案设计 |
| --- | --- | --- |
| 统一目录 | 系统入口散落在群消息、文档和个人收藏夹 | 以系统目录统一管理 78 条首批入口 |
| 个人常用 | 静态推荐无法适应不同岗位 | 管理员默认常用 + 用户个人加入/取消 |
| 按权展示 | 所有人看到同一入口集合 | 按用户、部门、角色和组织范围过滤 |
| 多形态入口 | App、小程序和网页混在同一链接列表 | 按入口形态提供跳转、提示或禁用行为 |
| SSO 闭环 | 用户进入目标系统后仍需重复登录 | 已接入系统生成 SSO 跳转地址，未接入系统明确标识 |
| 状态透明 | 待开启、开发中或地址缺失的入口仍可能造成无响应点击 | 卡片展示状态，不可访问时阻止无效跳转 |

### 2.4.3 方案结论

MVP 采用「统一系统目录 + 业务分类 + 个人常用 + 按权展示 + SSO 跳转 + 多入口形态」方案。系统清单以附录 6.1 的 78 条原始数据为基线；常用为用户级动态能力，不作为系统归属架构；所有网页型入口默认在新标签页打开。

# 3. 功能需求

## 3.1 全局通用规则

本节定义系统入口模块的通用行为规范，各子功能默认遵循此约定，特殊场景在模块内单独说明。

### 3.1.1 系统范围

| 规则项 | 说明 |
| --- | --- |
| 首版系统范围 | 以附录 6.1 的 78 条系统清单为准 |
| 数据真实性 | 系统名称、网址、使用部门和归属架构按原始清单展示；缺失项显示「—」，不得由前端自行补值 |
| 同名系统 | 同名但网址不同的系统作为独立入口保留，通过使用部门、访问地址或管理员补充说明区分 |
| 展示前提 | 系统未被停用，且当前用户命中可见范围；待开启/开发中的系统允许展示状态但不可访问 |
| 目标系统职责 | 工作台只负责入口展示、权限判断和发起访问，不承载目标系统内部业务 |

### 3.1.2 业务分类规则

| 规则项 | 说明 |
| --- | --- |
| 分类方式 | 系统可配置一个或多个业务分类 |
| 默认分类 | 常用 |
| 常用性质 | 常用是用户偏好集合，不是系统归属架构 |
| 建议分类 | B2C/线上业务、B2B/平台业务、直播业务、商品/供应链、仓储/履约、财务、客服/工单、数据/BI、技术/项目、内容/视觉、KA/对外项目、管理/OA |
| 分类来源 | 管理员依据主要使用业务域配置，不依据域名自动推断 |
| 分类顺序 | 后台配置排序；常用固定置于第一位 |
| 多分类系统 | 在所有命中的分类中展示，但同一分类内不得重复 |
| 分类计数 | 展示当前用户在该分类下可见系统数量 |

### 3.1.3 系统归属架构规则

| 规则项 | 说明 |
| --- | --- |
| 可选值 | B2C、B2B、中台、对外、— |
| 数据来源 | 以系统清单或管理员配置为准 |
| 对外含义 | 「对外」仅代表系统归属架构，不决定浏览器打开方式 |
| 缺失处理 | 原始清单未提供时显示「—」，由系统负责人后续补录 |
| 展示方式 | 作为系统卡片的架构标签展示，可用于识别但不作为访问权限依据 |

### 3.1.4 入口形态、状态与打开规则

| 入口形态 | 判断依据 | 点击行为 |
| --- | --- | --- |
| 网页系统 | 配置有效 HTTP/HTTPS 地址 | 完成权限与状态校验后，在新标签页打开 |
| App 下载页 | 配置 App Store 或下载地址 | 在新标签页打开下载页；其他平台说明以弹窗展示 |
| 微信小程序 | 配置小程序名称，无网页地址 | 弹窗展示「请在微信中搜索：{小程序名称}」 |
| 安装包获取 | 配置联系人或获取说明 | 弹窗展示获取方式，不执行网页跳转 |
| 状态覆盖：待开启/开发中 | 任意入口的状态为待开启或开发中 | 忽略入口形态的默认行为，卡片置灰，点击展示状态说明 |
| 后端服务 | 入口类型为后端服务 | 不面向普通员工跳转，点击展示「该系统为后端服务，无前台访问入口」 |
| 地址缺失 | 无网址且无其他访问说明 | 卡片置灰，点击展示「访问方式未配置」 |

### 3.1.5 常用规则

| 规则项 | 说明 |
| --- | --- |
| 常用来源 | 管理员默认常用 + 当前用户个人常用 |
| 加入入口 | 系统卡片右上角空心星标 |
| Hover 提示 | 未加入时提示「加入常用」；已加入时提示「取消常用」 |
| 加入结果 | 星标变为高亮实心，系统立即出现在常用分类，提示「已加入常用」 |
| 取消结果 | 星标恢复空心，系统立即从常用分类移除，提示「已取消常用」 |
| 事件隔离 | 点击星标只切换常用状态，不触发系统卡片跳转 |
| 持久化 | 常用状态按 userId 保存并跨设备同步 |
| 默认常用 | 用户可取消管理员设置的默认常用；取消结果按个人账号保存 |
| 数量上限 | MVP 不设置硬上限，超出可视区域后在系统列表内部滚动 |
| 权限变化 | 系统停用或用户失去权限后，入口从常用分类隐藏，但后台保留偏好记录；恢复权限后重新显示 |

### 3.1.6 SSO 与权限规则

| 规则项 | 说明 |
| --- | --- |
| 门户认证 | 用户必须先通过统一 SSO 登录门户 |
| 展示权限 | 系统列表按用户、部门、角色或组织范围过滤 |
| 二次校验 | 点击系统入口时，服务端必须再次校验身份、权限和系统状态 |
| 已接入 SSO | 服务端生成 SSO 跳转地址，目标系统完成免登 |
| 未接入 SSO | 打开系统原始地址，并在卡片展示「需登录」状态 |
| 凭证过期 | 静默刷新后自动重试一次；仍失败则提示重新登录 |
| 协议复用 | 具体 IAM、OAuth2、JWT 生命周期和验签方式以统一 SSO PRD 为准 |
| 安全边界 | 前端不得自行修改目标地址、拼接越权参数或绕过服务端访问校验 |

### 3.1.7 加载态 / 空态 / 错误态

| 场景 | 状态 | 处理方式 |
| --- | --- | --- |
| 系统列表加载 | 加载中 | 展示系统卡片骨架屏 |
| 系统列表加载 | 加载失败 | 展示错误提示和「重新加载」按钮 |
| 当前用户无可见系统 | 空 | 展示「暂无可访问的系统，请联系管理员开通」 |
| 常用分类 | 空 | 展示「还没有常用系统，可点击系统卡片右上角星标加入」 |
| 业务分类 | 空 | 展示「该分类下暂无可访问系统」 |
| 常用操作 | 保存中 | 星标进入短暂加载态，阻止重复点击 |
| 常用操作 | 保存失败 | 回滚星标状态，提示「操作失败，请重试」 |
| 系统访问 | 权限不足 | 阻止跳转，提示「暂无该系统访问权限」 |
| 系统访问 | 系统停用 | 阻止跳转，提示「该系统已停用」 |
| 系统访问 | SSO 失败 | 提示「免登失败，请重新登录或联系管理员」 |
| 系统访问 | 地址无效 | 阻止跳转，提示「系统地址无效，请联系管理员」 |
| 系统访问 | 浏览器拦截新窗口 | 提示「新窗口被浏览器拦截，请允许后重试」 |
| 全局网络 | 断连 | 页面顶部展示 Banner：「网络连接已断开，请检查网络」 |

### 3.1.8 并发与防重复规则

| 规则项 | 说明 |
| --- | --- |
| 分类切换 | 快速连续切换以最后一次选择为准 |
| 常用操作 | 同一系统请求未完成前禁止再次点击 |
| 系统访问 | 1 秒内同一用户对同一系统的重复点击只发起一次访问请求 |
| 新标签页 | 每次有效访问只打开一个新标签页 |
| 数据刷新 | 常用操作成功后局部更新，不重新加载整页 |

### 3.4.1 系统目录管理

#### ① 功能需求描述

系统目录管理用于维护所有系统入口的业务信息和访问配置。首版以附录 6.1 的 78 条原始清单初始化，管理员可在后台修改系统信息、业务分类、入口形态、访问状态和排序。

| EARS 模式 | 需求描述 |
| --- | --- |
| 普遍型 | 系统应为每个入口维护唯一 ID、名称、网址/访问说明、使用部门、归属架构、入口形态、分类、状态、排序和可见范围。 |

### 3.4.2 权限与 SSO 配置

#### ① 功能需求描述

权限与 SSO 配置用于决定系统入口对谁可见、谁可访问，以及点击后采用免登跳转还是原始地址跳转。前台展示权限与点击访问权限均由服务端判断，避免仅依赖前端隐藏。

| EARS 模式 | 需求描述 |
| --- | --- |
| 普遍型 | 系统应支持按用户、部门、角色和组织范围配置入口可见性，并支持逐系统配置 SSO。 |
| 状态驱动型 | 当用户无权限或系统停用时，访问服务应拒绝生成跳转地址。 |
| 事件驱动型 | 当用户点击入口时，服务端应重新校验身份、权限、状态与 SSO 配置。 |
| 不良行为型 | 前端不应直接基于页面数据拼接免登地址；服务端不应向无权限用户返回有效跳转地址。 |

#### ② 业务主流程图及说明

~~~mermaid
flowchart TD

    B -->|失效| C["刷新凭证并重试一次"]
    B -->|有效| D["校验系统状态"]
    D -->|不可用| E["拒绝访问"]
    D -->|可用| F["校验用户权限"]
    F -->|无权限| E
    F -->|有权限| G{"是否接入 SSO"}
    G -->|是| H["生成短时 SSO 跳转地址"]
    G -->|否| I["返回原始地址"]
    H --> J["记录访问审计"]
    I --> J
~~~

说明：前台只消费访问服务返回的结果，不持有系统间共享密钥。

### 3.5.1 整体布局与分类

#### 功能需求描述

系统入口模块由标题区、分类栏和系统卡片区构成。分类栏固定展示在卡片区顶部，「常用」固定为第一项并默认选中；系统卡片区在内容超出时内部滚动，避免拉长整个工作台页面。

| 事件驱动型 | 当用户点击分类时，系统应切换至该分类并展示命中的可见系统。 |

### 3.5.2 系统卡片与入口形态

### 3.5.3 个人常用

#### 功能需求描述

个人常用用于沉淀当前用户的高频系统入口。管理员可提供默认常用，用户可以在任意系统卡片上加入或取消；个人操作结果优先于管理员默认值。

| EARS 模式 | 需求描述 |
| --- | --- |
| 普遍型 | 系统应在每张可见系统卡片右上角展示常用星标，并按账号保存常用状态。 |
| 状态驱动型 | 当系统已加入常用时展示高亮实心星标，未加入时展示空心星标。 |
| 事件驱动型 | 当用户点击星标时，系统应切换常用状态、更新常用分类并给出反馈。 |
| 不良行为型 | 星标点击不应触发系统跳转；保存失败不应保留错误的本地状态。 |

### 3.5.4 系统访问与 SSO

#### 功能需求描述

系统访问负责在用户点击卡片后完成二次权限校验、系统状态校验、入口形态判断和跳转结果返回。已接入 SSO 的网页系统免登访问；未接入系统打开原始地址并允许目标系统自行登录。

| EARS 模式 | 需求描述 |
| --- | --- |
| 普遍型 | 系统应在每次点击访问时校验用户、权限、系统状态和入口配置，并记录访问结果。 |
| 状态驱动型 | 当凭证过期时系统应静默刷新并重试一次；当 SSO 未接入时返回原始地址。 |
| 事件驱动型 | 当访问校验通过时，网页/App 下载页应在新标签页打开；小程序等应展示访问说明。 |
| 不良行为型 | 系统不应在无权限、停用或配置无效时生成可访问地址。 |

#### 业务主流程图及说明

~~~mermaid
flowchart TD
    A["点击系统卡片"] --> B["防重复点击"]
    B --> C["调用访问接口"]
    C --> D{"校验结果"}
    D -->|无权限/停用/无效| E["阻止访问并提示原因"]
    D -->|通过| F{"返回动作"}
    F -->|open_new_tab| G["新标签页打开"]
    F -->|show_instruction| H["弹窗展示访问说明"]
    F -->|blocked| E
    G --> I["记录访问成功/失败"]
    H --> I
~~~

说明：浏览器是否成功加载目标系统不完全受门户控制；门户至少记录访问地址生成和窗口打开结果。

#### 界面原型

| 动作 | 显示 | 类型 | 描述 | 截图示例 |
|------|------|------|------|---------|
| 【可访问卡片】点击 | 卡片短暂加载 | 卡片 | · 1 秒内重复点击仅处理一次 | — |
| 【已接入 SSO】访问 | 新标签页免登进入 | 跳转 | · 卡片展示「免登」· 失败展示明确提示 | — |
| 【未接入 SSO】访问 | 新标签页打开原始地址 | 跳转 | · 卡片展示「需登录」 | — |
| 【凭证过期】访问 | 静默刷新后自动重试 | 系统行为 | · 用户无需重复点击 · 最多重试一次 | — |
| 【浏览器拦截】发生 | 提示允许新窗口 | Toast | · 不重复创建访问记录 | — |

#### 数据说明（业务实体）

| 字段名 | 数据类型 | 长度 | 默认值 | 必需 | 约束说明 |
|--------|---------|------|--------|------|---------|
| accessId | 字符 | 36 | 系统生成 | Y | · 单次访问请求标识 |
| userId | 字符 | 36 | 当前用户 | Y | · 访问用户 |
| systemId | 字符 | 36 | — | Y | · 目标系统 |
| actionType | 枚举 | — | blocked | Y | · open_new_tab/show_instruction/blocked |
| targetUrl | 字符 | ≤2048 | 空 | N | · 仅 open_new_tab 返回 |
| instruction | 字符 | ≤500 | 空 | N | · 仅 show_instruction 返回 |
| ssoUsed | 布尔 | — | false | Y | · 是否使用 SSO |
| result | 枚举 | — | pending | Y | · pending/success/failure/blocked |
| errorCode | 字符 | ≤50 | 空 | N | · 失败或阻止原因 |
| createdAt | 时间戳 | — | 当前时间 | Y | · 访问发起时间 |

#### 业务规则和约束条件

| 规则项 | 说明 |
| --- | --- |
| 打开方式 | 所有网页系统和 App 下载页默认新标签页 |
| SSO 标识 | 只有配置有效且启用 SSO 的系统展示「免登」 |
| 原始登录 | 未接入 SSO 的网页系统展示「需登录」并打开原始地址 |
| 凭证失效 | 静默刷新并重试一次，失败后引导重新登录 |

| --- | --- |

#### 补充说明

- SSO 的技术细节引用统一 SSO 方案，本节作为系统入口侧的验收依据。
- 目标系统自身不可用时，若门户无法在跳转前探测，则由目标系统错误页承接；门户记录用户发起访问事件。

### 3.5.5 状态反馈与异常处理

#### 功能需求描述

状态反馈用于覆盖列表加载、分类空态、常用操作、权限校验、入口配置和跳转过程中的异常，确保用户能够理解当前状态并采取下一步行动。

| EARS 模式 | 需求描述 |
| --- | --- |
| 普遍型 | 系统应为加载、空数据、保存、权限、状态、地址、SSO 和网络异常提供明确反馈。 |
| 状态驱动型 | 当系统不可访问时应保留系统名称和原因，不展示空白卡片或无响应点击。 |
| 事件驱动型 | 当可重试错误发生时，系统应提供重试入口并保留当前分类和滚动位置。 |
| 不良行为型 | 系统不应在失败后错误改变常用状态，不应连续打开多个空白标签页。 |

    B -->|访问说明| I["弹窗展示 App/小程序/安装包信息"]

说明：错误反馈不得清空用户已选择的分类，也不得改变已经成功保存的个人常用。

## 4.1 性能要求

| 指标 | 目标值 | 说明 |

| 并发访问 | 单用户同系统 1 秒内仅处理 1 次 | 防止重复打开标签页 |
| 配置生效 | ≤ 60s | 管理员保存后前台新请求可读取 |

## 4.2 安全要求

| 维度 | 要求 |
| --- | --- |
| 身份认证 | 统一 SSO（公司 IAM）；具体 Token 有效期和续期策略遵循统一 SSO PRD |
| 权限控制 | 列表查询与访问请求均由服务端执行用户/部门/角色/组织权限校验 |
| 跳转地址 | 前端仅使用访问服务返回地址，不自行拼接长期凭证或共享密钥 |
| 传输加密 | 门户与服务端使用 HTTPS；HTTP 目标地址需展示风险标识并推动升级 |
| 地址安全 | 后台校验 URL 协议，禁止 javascript、data 等可执行协议 |
| 防开放重定向 | 目标域名必须来自系统目录配置，访问接口不得接受前端任意 redirectUrl |
| 凭证保护 | 日志不得记录完整 Token、SSO Ticket 或敏感查询参数 |
| 数据最小化 | 系统入口只记录访问审计，不采集用户在目标系统内的业务数据 |
| 管理权限 | 只有系统入口管理员可修改目录、权限和 SSO 配置 |
| 操作审计 | 记录系统配置变更、权限变更、SSO 配置变更、常用操作和访问结果 |

## 6.4 状态与枚举

### 6.4.1 入口形态

| 枚举值 | 中文名称 | 前台行为 |
| --- | --- | --- |
| web | 网页系统 | 访问校验后新标签页打开 |
| app | App 下载页 | 新标签页打开下载页，补充平台说明 |
| mini_program | 微信小程序 | 弹窗展示搜索说明 |
| package_request | 安装包获取 | 弹窗展示获取方式 |
| backend_service | 后端服务 | 不跳转，展示说明 |
| missing | 地址缺失 | 置灰并提示补充 |

### 6.4.2 系统状态

| 枚举值 | 中文名称 | 是否展示 | 是否允许访问 |
| --- | --- | --- | --- |
| enabled | 启用 | 是 | 按入口形态判断 |
| disabled | 停用 | 否 | 否 |
| coming_soon | 待开启 | 是 | 否 |
| developing | 开发中 | 是 | 否 |

### 6.4.3 访问结果

| 枚举值 | 中文名称 | 说明 |
| --- | --- | --- |
| open_new_tab | 新标签页打开 | 网页系统或 App 下载页 |
| show_instruction | 展示访问说明 | 小程序、安装包或其他文字说明 |
| blocked | 阻止访问 | 无权限、停用、待开启、开发中、后端服务或配置无效 |

### 6.4.4 系统归属架构

| 枚举值 | 说明 |
| --- | --- |
| B2C | 面向线上零售或消费者业务的系统架构归属 |
| B2B | 面向平台、商户、供应链或企业业务的系统架构归属 |
| 中台 | 为多个业务部门提供共享能力的中台系统 |
| 对外 | 面向外部项目、组织或合作方的系统架构归属 |
| — | 原始数据未提供归属架构 |
