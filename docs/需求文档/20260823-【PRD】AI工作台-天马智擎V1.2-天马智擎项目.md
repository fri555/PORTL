# 产品概述

## 产品概述

天马智擎 V1.2 聚焦两条主线：① 首页多模态与交互增强（更大/更多格式文件上传、子 agent 多模态理解、更长会话轮次、历史会话分组浏览、澄清卡优化、个人知识库检索、钉钉 dws 打通）；② 知识中心文件治理（下载权限、细粒度权限继承与黑名单、文件树实时同步）。

## 产品目标

1. 首页支持 mp4 等视频/图片多模态上传与理解。
2. 首页附件支持 20–30M 大表格及 html/emmx/ppt 格式。
3. 日常办公模式 ReAct 轮次上调至 20 次。
4. 历史会话按分组展开/收起，便于浏览。
5. 澄清卡支持一次澄清结束，必填不可跳过、非必填可跳过。
6. 首页日常办公模式可检索公共+个人知识库。
7. 提供友好前端界面配置模型/MCP/Tool/Skill/Agent。
8. 会话与知识库文件可设下载权限，增加管理角色。
9. 知识库/文件夹/文件权限细粒度管控（继承+黑名单）。
10. 通过 dws 打通钉钉，支持按群选人建日程等。
11. 知识中心右侧操作实时同步左侧文件树。

## 功能详情

### M1-多模态理解

#### 功能需求描述
作为普通用户，在天马智擎首页上传图片（重点）、视频等文件时，希望获得基于子 agent 的多模态理解能力，辅助回答与生成内容。

#### 用户角色与用户故事
作为一名普通用户，借助首页文件上传与多模态理解能力，完成对图片/视频内容的识别、提取与问答，减少手动描述成本。

#### 业务主流程图及说明
用户操作 / 系统反馈：
1. 用户在首页输入框点击【上传】，选择图片/视频（mp4 等）。
2. 系统校验格式与大小，调用对应子 agent 解析。
3. 解析结果（文本/截图/标签）进入对话上下文。
4. 用户基于文件提问，模型结合解析内容生成回答。

#### 分支流程（异常流程）
- 若上传格式不支持，系统应提示“不支持此格式”并阻断，不进入解析。
- 若解析超时/失败，系统应返回友好提示并保留原文件供重试，不中断会话。

### M3-ReAct 轮次

#### 功能需求描述
作为普通用户，在天马智擎首页会话详情中，希望日常办公模式的 ReAct 循环轮次上调至 20 次，以完成更复杂的多步任务。

#### 用户角色与用户故事
作为一名普通用户，借助更长的 ReAct 轮次，完成需要多步推理与工具调用的复杂任务，不必中途手动续接。

#### 业务主流程图及说明
用户操作 / 系统反馈：
1. 用户发起对话，进入日常办公模式。
2. 模型按 Reason→Act 循环：推理、调用工具/检索、观察结果。
3. 每轮计数 +1，直到任务完成或达上限。
4. 达上限仍未完成则提示用户是否继续/收尾。

#### 分支流程（异常流程）
- 若达到 20 轮仍未完成，系统应提示“已达轮次上限，是否继续/总结当前结果”。
- 若单轮工具调用超时，系统应跳过该步并继续下一轮，不中断会话。

### M11-文件树同步

#### 功能需求描述
作为普通用户，在知识中心文件管理同步时，希望右侧建文件夹、上传文件的操作能实时更新左侧文件树。

#### 用户角色与用户故事
作为一名普通用户，借助实时同步，在右侧完成建文件夹/上传后，左侧文件树即时反映最新结构，无需手动刷新。

#### 业务主流程图及说明
用户操作 / 系统反馈：
1. 用户在右侧区域新建文件夹/上传文件。
2. 操作完成触发同步事件。
3. 左侧文件树接收事件并更新节点。
4. 用户即时看到新增节点，可继续操作。

#### 分支流程（异常流程）
- 若同步失败（网络/服务异常），系统应提示“同步失败，点击重试”并保留操作结果。
- 若短时间内大量操作，系统应防抖合并更新，避免树频繁抖动。
