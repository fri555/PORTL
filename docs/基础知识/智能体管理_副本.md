# 智能体管理

## 一、需求背景

### 1. 价值与目的

**价值**：让企业内部智能体（Agent）可被创建、查找、编辑、发布和下线，形成最小可用的生命周期管理。

**目的**：解决当前智能体散落在各系统、无统一入口、无状态管理的问题。

### 2. 最痛 case

运营人员想修改一个已上线智能体的提示词，找不到入口；开发人员在代码里直接改完发布，出错后只能手动回滚，影响用户。

### 3. MVP 范围

**做**：

*   智能体创建（空白创建、从现有复制）、编辑、查询、删除、搜索、筛选
    
*   草稿 / 已发布 三态
    
*   发布
    

**不做**：

*   模板库
    
*   导入/导出
    
*   批量操作
    
*   依赖快照
    
*   监控图表 / 评估 / 试运行独立 Tab（监控指标在详情页内嵌展示）
    
*   多环境 / 灰度 / AB 实验
    
*   审批流
    
*   协作/分享
    

### 4. 场景假设

| 假设 | 说明 | 复盘点 |
| --- | --- | --- |
| 智能体规模 | MVP 智能体总数 < 100，单用户创建 < 30 | 超过需优化列表分页与搜索性能 |
| 无审批 | 创建即可用，发布即生效 | 事故多时再加审批流 |
| 版本仅线性 | 每次发布生成一个新版本，回滚即创建反向版本 | 分支版本场景 P1 再评估 |
| 单负责人 | 每个智能体仅一个负责人（创建者） | 多人协作 P1 引入协作者 |
| 试运行不收费 | 试运行消耗的 Token 不计入成本统计 | 若成本压力大，P1 增加配额限制 |
| 监控指标仅 24h | 详情页仅展示最近 24 小时数据 | 更大时间范围 P1 做独立监控页 |

## 二、用户故事

| 编号 | As a（角色） | I want（需求） | So that（目的） | 验收标准 |
| --- | --- | --- | --- | --- |
| US-01 | 普通用户 | 创建一个智能体并填写完整配置 | 快速配置一个可运行的智能体 | 创建后生成草稿，包含模型、提示词、工具、知识库等完整配置 |
| US-02 | 普通用户 | 编辑自己创建的智能体 | 调整智能体配置 | 保存后更新草稿或生成新草稿 |

| US-04 | 普通用户 | 将自己已发布的智能体归档 | 下线不再使用的智能体 | 归档后终端用户不可调用 |
| US-05 | 普通用户 | 删除自己创建的草稿 | 清理错误的草稿 | 仅草稿可删，删除后不可恢复 |
| US-06 | 平台用户 | 通过列表搜索和筛选找到智能体 | 快速定位需要的智能体 | 关键词、状态、分类、负责人筛选有效 |

| US-08 | 平台管理员 | 将已归档智能体恢复为草稿 | 重新启用历史智能体 | 恢复后可重新编辑发布 |
| US-09 | 普通用户 | 基于已有智能体复制创建新智能体 | 快速复用已有配置 | 复制后生成新草稿，名称和 slug 去重，负责人为新用户 |
| US-10 | 普通用户 | 在草稿状态下试运行调试智能体 | 发布前验证对话效果 | 草稿详情页可打开试运行面板，发送消息并查看回复 |
| US-11 | 普通用户 | 将已发布智能体回滚到历史版本 | 快速恢复线上故障 | 回滚后生成新版本，版本号递增，配置恢复为历史版本内容 |
| US-12 | 平台用户 | 在详情页查看智能体调用统计 | 了解智能体使用情况 | 详情页展示 24h 调用量、错误率、成本趋势 |

## 三、名词解释

| 术语 | 含义 |
| --- | --- |
| 智能体（Agent） | 基于 LLM 的可配置应用单元 |
| 草稿（Draft） | 编辑中状态 |
| 已发布（Published） | 对终端用户可用 |
| 已归档（Archived） | 不可调用，保留历史 |
| 版本号 | 发布时递增，格式 `major.minor`，MVP 仅记录 |
| 负责人 | 智能体创建者 |
| 试运行 | 草稿状态下的对话调试功能，用于发布前验证智能体效果 |
| 回滚 | 将已发布智能体恢复到历史版本配置，生成新版本号 |
| 调用统计 | 智能体被终端用户调用的次数、成功率、成本等指标 |
| 平台管理员 | 拥有全部操作权限的用户 |

## 四、产品方案

### 1. 方案决策

| 方案 | 描述 | 决定 |
| --- | --- | --- |
| 三态生命周期 | 草稿 → 已发布 → 已归档 | 采用 |
| 模板创建 | 从模板库创建智能体 | MVP 不做 |
| 版本回滚 | 回滚到历史版本 | 采用 |
| 从现有复制 | 基于已有智能体配置创建新智能体 | 采用 |
| 试运行 | 草稿状态下对话调试 | 采用 |
| 调用统计 | 详情页展示调用量、错误率、成本 | 采用（内嵌详情页） |
| 导入导出 | 批量导入/导出智能体 | MVP 不做 |
| 监控图表 | 独立监控 Tab 展示运行数据 | MVP 不做（P1） |
| 评估 Tab | 独立 Tab 展示评估结果 | MVP 不做（P1） |
| 协作分享 | 多人共同管理一个智能体 | MVP 不做 |

### 2. 功能闭环

```plaintext
创建（空白 / 从现有复制） → 编辑配置 → 保存草稿 → 试运行 → 发布
                ↓                           ↓
             列表查询 ← 搜索/筛选 ← 编辑（生成新草稿）
                ↓                           ↓
             归档 / 删除（仅草稿）         回滚（历史版本 → 新版本）
                ↓
             恢复为草稿（管理员）

```

### 3. 状态机

```plaintext
   草稿 ──发布──▶ 已发布 ──归档──▶ 已归档
    │              │  ▲              │
    │ 删除         │  │ 回滚         │ 恢复（仅管理员）
    ▼              ▼  │              ▼
  已删除        历史版本          草稿

```

**规则**：

*   草稿 → 已发布：发布时生成新版本号，写入版本历史
    
*   已发布 → 草稿：编辑时创建新草稿，原已发布版本不变，仍可被调用
    
*   已发布 → 已发布（回滚）：选择历史版本回滚，生成新版本号，配置恢复为历史版本内容
    
*   已发布 → 已归档：归档后不可调用
    
*   已归档 → 草稿：仅平台管理员可恢复，恢复后可编辑
    
*   草稿 → 已删除：仅草稿可删除，物理删除
    

## 五、业务规则

### 1. 字段规则

智能体包含以下信息：

**基础信息**：

*   名称：必填，1-100 字符，同一负责人下唯一
    
*   描述：可选，≤500 字符
    
*   图标：可选，从图标库选择
    
*   分类：必填，≤30 字符，可选择已有或输入新值
    
*   角色：必填，单选：通用 / 专家
    

**模型与提示词**：

*   模型：创建时必填，仅可选择已启用模型
    
*   温度：可选，0-2，步进 0.1，默认 0.7
    
*   最大输出 Token：可选，1-100000 整数，默认 8192
    
*   系统提示词：必填，1-10000 字符
    
*   指令列表：可选，最多 20 条，每条 ≤500 字符
    

**能力配置**：

*   工具：可选，仅可多选已启用工具
    
*   知识库：可选，多选
    
*   启用记忆：可选，默认关闭
    
*   记忆窗口：启用记忆后必填，1-100 整数，默认 10
    

### 2. 分类规则

*   分类支持用户自由创建，系统预置常用分类：通用、客服、销售、研发、运营
    
*   用户输入新分类时即时创建，无需单独审批
    
*   分类名称 ≤30 字符，不支持特殊字符 `/\<>`
    
*   MVP 不做独立的分类管理后台，P1 评估是否需要统一维护
    

### 3. 唯一性规则

*   同一负责人下，智能体名称不能重复
    
*   不同负责人可拥有同名智能体
    
*   slug 全局唯一，由系统根据名称自动生成，重名时追加序号
    

### 4. 版本号规则

*   创建草稿时默认版本号为 `0.1`
    
*   发布时版本号 minor +1，如 `1.2` → `1.3`
    
*   回滚时版本号 minor +1，版本历史记录回滚来源（如：`1.4 (回滚自 v1.2)`）
    
*   编辑已发布智能体生成的新草稿，版本显示为 `原版本-draft`，如 `1.3-draft`
    
*   恢复已归档智能体生成的新草稿，版本显示为 `原版本+0.1-draft`
    

### 5. 发布规则

*   仅草稿状态可发布
    
*   发布时所有必填项必须完整
    
*   引用的主模型必须处于启用状态
    
*   引用的工具必须处于启用状态
    
*   知识库已删除时仅警告，不阻断发布
    
*   发布时必须填写变更说明（5-200 字符）
    
*   发布成功后，旧已发布版本自动归档
    

### 6. 回滚规则

*   仅已发布状态可回滚
    
*   负责人或平台管理员可回滚
    
*   回滚目标必须是历史已发布版本
    
*   回滚生成新版本号（minor +1），不删除中间版本
    
*   回滚时若目标版本配置中模型/工具已禁用，警告但不阻断
    
*   回滚时必须填写回滚原因（5-200 字符）
    
*   回滚后异步通知引擎加载新配置
    

### 7. 编辑规则

*   草稿：直接编辑当前记录
    
*   已发布：编辑时创建新草稿，原已发布版本保持不变并继续可用
    
*   已归档：不可直接编辑，需管理员恢复为草稿后编辑
    

### 8. 删除规则

*   仅草稿状态可删除
    
*   负责人或平台管理员可删除
    
*   删除需输入名称二次确认
    
*   删除后不可恢复
    

### 9. 归档规则

*   仅已发布状态可归档
    
*   负责人或平台管理员可归档
    
*   归档需勾选确认
    
*   归档后终端用户不可调用
    

### 10. 恢复规则

*   仅已归档状态可恢复
    
*   仅平台管理员可恢复
    
*   恢复需填写原因（5-200 字符）
    
*   恢复后创建新草稿，需重新发布才能上线
    

## 六、权限规则

| 操作   | 普通用户（自己创建）           | 普通用户（他人创建）       | 平台管理员 |
| ---- | -------------------- | ---------------- | ----- |
| 查看列表 | ✅（可见 published 和自己的） | ✅（仅可见 published） | ✅（全部） |
| 查看详情 | ✅                    | ❌                | ✅     |
| 创建   | ✅                    | \-               | ✅     |
| 编辑   | ✅                    | ❌                | ✅     |
| 发布   | ✅                    | ❌                | ✅     |
| 归档   | ✅                    | ❌                | ✅     |
| 回滚   | ✅                    | ❌                | ✅     |
| 恢复   | ❌                    | ❌                | ✅     |
| 删除   | ✅                    | ❌                | ✅     |

**说明**：

*   普通用户只能操作自己创建的智能体
    
*   普通用户在列表中可以看到所有 `published` 状态的智能体，但无法查看详情和编辑
    
*   平台管理员可操作所有智能体
    

## 七、功能设计

### 1. 智能体列表页

#### 1.1 页面布局

```plaintext
┌─────────────────────────────────────────────────────────────┐
│ 智能体管理                              [新建智能体]        │
├─────────────────────────────────────────────────────────────┤
│ 关键词 [________] 状态 [全部▼] 分类 [全部▼] 负责人 [全部▼]    │
│ 创建时间 [____~____] 排序 [更新时间▼] [升序/降序]           │
├─────────────────────────────────────────────────────────────┤
│ 名称 │ 分类 │ 角色 │ 状态 │ 负责人 │ 版本 │ 更新时间 │ 操作 │
├──────┼──────┼──────┼──────┼────────┼──────┼──────────┼──────┤
│ ...  │      │      │      │        │      │          │      │
├─────────────────────────────────────────────────────────────┤
│ 共 100 条 / 第 1 页                              [20▼/页]   │
└─────────────────────────────────────────────────────────────┘

```

#### 1.2 筛选与搜索

| 控件 | 类型 | 默认值 | 说明 | 交互 |
| --- | --- | --- | --- | --- |
| 关键词 | 输入框 | 空 | 匹配名称、描述、slug，≤50 字符 | 输入防抖 300ms 后自动刷新 |
| 状态 | 单选下拉 | 全部 | 草稿 / 已发布 / 已归档，默认不包含已归档 | 选择后立即刷新 |
| 分类 | 单选下拉 | 全部 | 从所有智能体分类去重获取，支持预置分类 + 用户自建分类 | 选择后立即刷新 |
| 负责人 | 单选下拉 | 全部 | 所有有智能体的用户 | 选择后立即刷新 |
| 创建时间 | 日期范围 | 全部 | 起始 ≤ 结束 | 选择后自动刷新 |
| 排序 | 单选下拉 | 更新时间 | 创建时间 / 更新时间 / 名称 | 选择后立即刷新 |
| 排序方向 | 单选 | 降序 | 升序 / 降序 | 点击后立即刷新 |

**筛选条件保留**：

*   所有条件同步到 URL Query 参数
    
*   刷新页面后保留筛选状态
    
*   点击浏览器返回时恢复上一次的筛选状态
    

**校验**：

*   起始时间 > 结束时间：提示“结束时间不能早于开始时间”，不触发查询
    

#### 1.3 表格列

| 列名 | 说明 | 可排序 | 宽度 |
| --- | --- | --- | --- |
| 名称 | 图标 + 名称 + 下方灰字 slug | ✅ | 自适应，最小 200px |
| 分类 | 标签 | ❌ | 100px |
| 角色 | `通用` / `专家` 标签 | ❌ | 90px |
| 状态 | 彩色标签：草稿（灰）、已发布（绿）、已归档（橙） | ❌ | 90px |
| 负责人 | 头像 + 用户名 | ❌ | 140px |
| 版本 | 当前版本号 | ❌ | 80px |
| 更新时间 | 相对时间，hover 显示完整时间 | ✅ | 140px |
| 操作 | 编辑 / 更多下拉 | \- | 120px |

**”更多”下拉内容按状态**：

*   草稿：编辑、复制、发布、删除
    
*   已发布：编辑（生成新草稿）、复制、回滚、归档
    
*   已归档：查看、复制（仅管理员）、恢复为草稿（仅管理员可见）
    

#### 1.4 分页

*   默认 20/页，下拉切换 50/100
    
*   底部分页器：首页、上一页、页码、下一页、末页、跳转输入框
    
*   展示文案：“共 {total} 条 / 第 {page} 页 / 共 {pages} 页”
    
*   切换 page\_size 后回到第 1 页
    

#### 1.5 列表状态

| 状态 | 触发条件 | 展示 |
| --- | --- | --- |
| 加载中 | 首次进入 / 筛选变化 | 骨架屏：表头 + 5 行占位 |
| 空数据 | 用户没有任何可见智能体 | 空状态插画 + “还没有智能体” + “新建智能体”按钮 |
| 搜索无结果 | 有筛选条件但结果为空 | “没有符合筛选条件的智能体” + “清空筛选”按钮 |
| 加载失败 | 接口报错 | 红色文字 “加载失败，请重试” + “重试” 按钮 |

#### 1.6 操作交互

**编辑**：

*   草稿：直接打开编辑页
    
*   已发布：弹窗提示“编辑将创建新草稿，原已发布版本 v{x.y} 保持不变”，确认后打开编辑页
    
*   已归档：无编辑入口
    

**发布**（仅草稿）：

*   点击后弹窗：输入变更说明（必填 5-200 字符）
    
*   若校验失败：弹窗内展示失败原因，确认发布按钮禁用
    
*   成功后：列表状态刷新为已发布
    

**归档**（仅已发布）：

*   点击后弹窗：文案 + 必勾确认框
    
*   未勾选时确认按钮禁用
    
*   成功后列表刷新
    

**复制**：

*   任意状态（普通用户仅可复制已发布，管理员可复制全部）
    
*   点击后直接进入新建页，预填源智能体配置
    
*   名称自动填充为"{原名称} (副本)"
    

**回滚**（仅已发布）：

*   点击后弹窗：选择目标版本（默认上一版本）+ 输入回滚原因（必填 5-200 字符）
    
*   若目标版本配置中模型/工具已禁用，弹窗内展示警告但不阻断
    
*   成功后列表状态不变（仍为已发布），版本号更新
    

**删除**（仅草稿）：

*   点击后弹窗：文案 + 输入名称二次确认
    
*   名称不匹配时确认按钮禁用
    
*   成功后列表刷新 + toast

#### 2.2 页面结构

```plaintext

│ 新建智能体                                                  │
```

#### 2.4 按钮与操作

*   **保存草稿**：
    
    *   校验字段格式（不强制必填）
        
    *   有格式错误时提示并定位
        
    *   保存成功后跳转详情页，toast “智能体 {名称} 已创建为草稿”
        
*   **保存并发布**：
    
    *   校验所有必填项
        
    *   校验引用模型/工具启用状态
        
    *   弹窗输入变更说明（必填 5-200 字符）
        
    *   确认后发布，跳转详情页，toast “已发布 v{版本号}”
        
*   **取消**：
    
    *   若表单有修改：弹窗确认“未保存的修改将丢失”
        
    *   若表单无修改：直接返回列表
        

#### 2.5 创建后

*   生成草稿记录，负责人为当前用户
    
*   slug 自动生成：基于名称转小写 + 连字符，重名时追加序号（如 `ke-fu-zhu-shou-2`）
    
*   默认版本号 `0.1`
    
*   跳转智能体详情页

### 6. 发布流程

#### 6.1 入口

*   编辑页“保存并发布”
    
*   列表页草稿状态“发布”
    
*   详情页草稿状态”发布”
    

#### 6.2 发布校验

| 检查项 | 是否阻断 | 失败处理 |
| --- | --- | --- |
| 必填项完整 | 是 | 提示“必填项未填写完整：{字段列表}”，定位到错误 Tab |
| 主模型已启用 | 是 | 提示“模型 {名称} 已禁用，请更换” |
| 工具全部已启用 | 是 | 提示“工具 {名称} 已禁用，请先启用或移除” |
| 知识库已删除 | 否 | 警告“知识库 {名称} 已删除，请移除” |
| 变更说明 | 是 | 提示“请输入变更说明（5-200 字）” |

#### 6.3 发布弹窗

*   标题：发布智能体
    
*   当前版本号展示
    
*   变更说明输入框（必填，5-200 字符）
    
*   若校验有阻断项：展示错误列表，“确认发布”按钮禁用
    
*   按钮：取消 / 确认发布
    

#### 6.4 发布后

*   当前草稿状态变为已发布，版本号更新
    
*   旧已发布版本（如有）自动归档
    
*   写入版本历史
    
*   异步通知引擎加载
    
*   Toast："已发布 v{版本号}"
    

### 10. 删除流程

#### 10.1 入口

*   列表页草稿状态“删除”按钮（仅自己创建或管理员）
    
*   详情页”删除”按钮（仅草稿状态，且仅自己创建或管理员）
    

#### 10.2 确认弹窗

*   标题：删除智能体
    
*   文案：“确定删除智能体 {名称}？此操作不可恢复。”
    
*   输入框：填入智能体名称二次确认
    
*   按钮：取消 / 确认删除
    
*   名称不匹配时确认按钮禁用，提示“请正确输入智能体名称”
    

#### 10.3 删除规则

*   仅草稿状态可删除
    
*   负责人或管理员可删除
    
*   删除后不可恢复
    
*   删除后返回列表，toast “已删除”

## 九、异常与边界

### 1. 核心异常

| 场景 | 前端表现 | 业务处理 |
| --- | --- | --- |
| 名称重复 | 输入框下方红字提示 | 拒绝保存 |
| 引用模型已禁用 | 模型选择框标红，发布弹窗展示错误 | 阻断发布 |
| 引用工具已禁用 | 工具项标红，发布弹窗展示错误 | 阻断发布 |
| 非草稿状态删除 | 隐藏删除入口 | 拒绝操作 |
| 无权限操作 | 按钮禁用或无入口 | 拒绝操作 |
| 并发编辑 | 后保存者提示“内容已被更新，请刷新” | 提示冲突 |
| 智能体不存在 | 404 页面 | 拒绝操作 |
| 网络异常 | 操作按钮恢复，toast 提示重试 | 可重试 |
| 试运行模型不可用 | 提示"当前选择的模型不可用" | 阻止发送消息 |
| 试运行超时（30s） | 提示"响应超时，请重试" | 用户可重试 |
| 回滚目标版本配置中模型已禁用 | 弹窗警告但不阻断 | 回滚后提示更新模型 |
| 回滚目标版本配置中工具已禁用 | 弹窗警告但不阻断 | 回滚后提示更新工具 |
| 回滚时目标版本不存在 | 提示"目标版本不存在" | 拒绝操作 |

| 复制时源智能体模型/工具已禁用 | 对应字段标红提示 | 用户可修改后保存 |

### 2. 边界情况

| 场景 | 处理 |
| --- | --- |
| 创建时名称与他人重复 | 同一负责人下唯一，不同负责人可重名 |
| 发布时知识库已删除 | 警告但不阻断，运行时引擎处理缺失 |
| 编辑已发布时原记录被归档 | 仍创建新草稿，基于当前已发布内容 |
| 恢复已归档时原负责人已离职 | 新草稿负责人保持原负责人，管理员可转交 |
| 切换模型后 temperature 不兼容 | 前端不做限制，后端按模型实际范围处理 |
| 回滚到已禁用模型的版本 | 允许回滚但警告，回滚后提示需更新模型 |
| 试运行中切换草稿模型 | 清空当前对话历史，提示"模型已切换，对话已清空" |
| 复制已归档智能体 | 管理员可复制，普通用户不可复制已归档智能体 |
| 回滚后立即再次回滚 | 允许，每次回滚均生成新版本号 |
| 调用统计中智能体从未被调用 | 展示空状态，不显示 0 值图表 |

## 十、上下游影响

### 1. 上游依赖

| 系统 | 影响 | 应对 |
| --- | --- | --- |
| 模型管理 | 模型禁用影响智能体发布 | 发布时校验模型状态 |
| 工具管理 | 工具禁用影响智能体发布 | 发布时校验工具状态 |
| 知识库系统 | 知识库删除影响智能体调用 | MVP 仅做存在性校验，运行时引擎处理 |
| 用户中心 | 负责人信息 | 调用用户中心接口获取用户列表 |

### 2. 下游影响

| 系统 | 影响 | 应对 |
| --- | --- | --- |
| C 端聊天应用 | 智能体发布/归档影响可用性 | 调用时校验状态 |
| 审计日志 | 创建/编辑/发布/归档/删除需记录 | 接入统一审计日志 |
| 智能体引擎 | 发布/回滚/归档后的配置需同步到引擎 | 发布/回滚/归档后异步通知引擎 |
| 监控/日志系统 | 调用统计数据来源 | 复用现有 Tracing/日志数据，新增 agent\_id 维度聚合 |
| 试运行引擎 | 草稿试运行需要独立的对话通道 | 试运行请求路由到沙箱环境，与正式调用隔离 |

## 十一、风险与缓解

| 风险 | 影响 | 可能性 | 缓解措施 |
| --- | --- | --- | --- |
| 用户直接编辑已发布智能体，未理解会生成新草稿 | 中 | 高 | 编辑前强弹窗说明；详情页清晰展示当前状态和版本 |
| 发布时引用的模型/工具被禁用，导致发布失败 | 中 | 中 | 发布前阻断校验；列表/详情页标记禁用资产 |
| 名称唯一性按负责人维度，不同用户创建同名智能体造成混淆 | 低 | 中 | slug 全局唯一；列表展示 slug 区分 |
| 归档后仍有 C 端会话在调用，出现报错 | 中 | 中 | 归档异步通知引擎；C 端做好兜底提示 |
| 版本历史只记录不清理，数据量增长 | 低 | 低 | MVP 可接受；P1 增加版本清理策略 |
| 并发编辑同一草稿导致覆盖 | 中 | 低 | 保存时校验更新时间，冲突时提示刷新 |
| 回滚后引用的模型/工具已禁用，智能体不可用 | 高 | 中 | 回滚前警告；回滚后详情页标记禁用资产 |
| 频繁回滚导致版本历史膨胀 | 低 | 低 | MVP 可接受；P1 增加版本数量上限或自动清理策略 |
| 试运行消耗大量 Token 导致成本增加 | 低 | 中 | 试运行不计入成本统计（MVP）；P1 增加试运行配额限制 |
| 调用统计数据不准导致误判 | 中 | 低 | 数据来源于调用日志，与 Tracing 数据对齐 |

## 十二、非功能性需求

### 1. 性能

| 场景 | 目标 | 说明 |
| --- | --- | --- |
| 列表页首次加载 | ≤ 500ms | 常规筛选，20 条/页 |
| 列表页筛选刷新 | ≤ 300ms | 防抖后接口响应 |
| 详情页加载 | ≤ 300ms | 包含完整配置和关联资产 |
| 创建/编辑保存 | ≤ 500ms | 常规配置 |
| 发布操作 | ≤ 1s | 包含校验和版本生成 |
| 回滚操作 | ≤ 2s | 包含配置恢复和通知 |
| 试运行响应 | ≤ 5s | 单次对话回复 |
| 调用统计数据刷新 | ≤ 300ms | 统计卡片和图表渲染 |

### 2. 安全

*   普通用户只能访问自己创建的智能体和所有已发布智能体的列表
    
*   管理员可操作全部智能体
    
*   删除操作需二次确认，防止误删
    
*   系统提示词等配置仅对授权用户可见
    

### 3. 可用性

*   列表页空状态、加载状态、错误状态需完整处理
    
*   表单错误需定位到具体字段和 Tab
    
*   关键操作（发布、归档、删除）需二次确认
    
*   长表单支持步骤导航和自动保存提示
    

### 4. 兼容性

*   支持主流浏览器：Chrome、Edge、Safari、Firefox 最新两个大版本
    
*   响应式适配：管理后台以桌面端为主，最低分辨率 1280×720
    

### 5. 数据一致性

*   发布成功后，已发布版本必须对终端用户立即可见或 5 秒内生效
    
*   回滚成功后，回滚配置必须在 5 秒内对终端用户生效
    
*   归档成功后，终端用户 5 秒内不可再调用
