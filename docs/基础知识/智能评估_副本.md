# 智能评估

## 一、需求背景

### 1. 价值与目的

**价值**：把评估从"配置项"提升为独立的"数据集 + 评估任务 + 报告"三件套，让智能体发布前有客观质量数据支撑。

**目的**：解决现有评估能力缺乏数据集版本管理、维度化指标、回归任务等问题。

**MVP 简化**：MVP 不做 Judge 校准、不做人审，仅做"LLM 直接打分 + 简单报告"。

### 2. 最痛 case

智能体负责人周宇改了一处 prompt 准备发布，没有客观评估数据，纠结"新版是否比旧版好"，不敢上线，迭代停滞。

### 3. PR release

*   **MVP**：数据集 CRUD（按状态区分） + 样本管理 + 评估任务 + 报告 + 智能体详情页评估趋势 + 排序/搜索/筛选/批量/导入/导出/复制；
    
*   P1：Judge 校准、人审、定时回归、工具/模型评估；
    
*   P2：在线评估、AB 实验、自动门禁。
    

## 二、场景假设

| 假设 | 说明 | 复盘点 |
| --- | --- | --- |
| 仅智能体评估 | MVP 仅做智能体端到端评估 | 工具/模型评估作为 P1 |
| 评估不强制 | 智能体发布前推荐跑评估但不强制阻断 | 质量事故多时改强制 |
| LLM 直接打分 | MVP 不做校准，Judge 原始分即最终分 | 偏差大时再做校准 |
| 评估并发 10 | 同时跑评估任务 ≤ 10 | 超过需评估任务队列 |
| 样本权重 | 支持样本级权重（1-10） | 复杂加权需新设计 |
| 评估数据集草稿可删 | 已发布数据集只能归档 | 防止误删历史 |

## 五、产品方案

### 1. 考虑的方案

| 方案 | 描述 | 优点 | 缺点 | 决定 |
| --- | --- | --- | --- | --- |
| A：独立评估模块 | 数据集/任务/报告独立，复用现有评估引擎 | 闭环完整、可扩展 | 需迁移现有配置 | ✅ 采用 |
| B：扩展现有配置 | 在 JSON 里扩展字段 | 改动小 | 无法支持多智能体 | ❌ 弃用 |
| C：接入开源评估库 | 使用开源评估库 | 开箱即用 | 定制能力弱 | ❌ 弃用 |

### 2. 长期方案

| 维度 | MVP | P1 | P2 |
| --- | --- | --- | --- |
| 评估对象 | 仅智能体 | 工具/模型 |  |
| 评估方式 | LLM 直接打分 | 校准 + 人审 | 多 Judge 投票 |
| 回归 | 手动跑 | 定时回归 | 在线评估 |
| 门禁 | 推荐 | 强制 | 自动门禁 |

### 3. 返工风险

| 返工点 | 风险 | 缓解 |
| --- | --- | --- |
| 增加工具/模型评估 | 低 | 预留评估对象类型扩展 |
| 强制门禁 | 低 | 智能体发布流程已预留接口 |
| 多 Judge 投票 | 中 | 预留多 Judge 接口 |

## 六、产品功能设计

### 1. 闭环

```plaintext
建数据集（CRUD）→ 管理样本 → 跑评估任务 → 看报告 → 迭代数据集
                                                       │
                                                       └─ 复制 / 导入 / 导出
```

### 2. 页面清单

| 页面       | 主要内容                        |
| -------- | --------------------------- |
| 数据集列表    | 筛选 + 搜索 + 列表 + 批量操作 + 导入/导出 |
| 数据集详情    | 概览 / 样本 / 版本历史 / 使用记录       |
| 新建/编辑数据集 | 元信息 + 样本编辑                  |
| 指标库      | 指标 CRUD + 预置 7 维度           |
| 评估任务列表   | 筛选 + 列表                     |
| 评估任务详情   | 进度 + 结果 + 样本详情              |
| 报告列表     | 筛选 + 列表                     |
| 报告详情     | 完整报告 + 导出                   |

### 3. 数据集状态机

```plaintext
   草稿 ──发布──▶ 已发布 ──编辑──▶ 草稿(新版本)
       │              │                  │
       │ 删除         │ 归档             │ 发布
       ▼              ▼                  ▼
   (已删除)        已归档            已发布(新版本)
                      │
                      │ 恢复(仅管理员)
                      └────▶ 草稿
```

**转换规则**：

*   草稿 → 已发布：用户点"发布"，生成版本号；
    
*   已发布 → 草稿（新版本）：用户点"编辑"，创建新版本草稿；
    
*   已发布 → 已归档：用户点"归档"；
    
*   已归档 → 草稿：仅平台管理员可"恢复为草稿"；
    
*   草稿 → 删除：仅草稿可删（输入名称二次确认）。
    

### 4. 数据集列表页

#### 4.1 筛选条 + 搜索

| 控件 | 类型 | 选项 | 默认值 | 校验 |
| --- | --- | --- | --- | --- |
| 状态 | 多选下拉 | 草稿 / 已发布 / 已归档 | 已发布 |  |
| 标签 | 多选下拉 | 已有标签 + 全部 | 全部 |  |
| 负责人 | 单选下拉 | 所有有数据集的用户 + "全部" | 全部 |  |
| 创建时间 | 日期范围选择 |  | 30 天内 | 起始 ≤ 结束 |
| 样本数 | 区间输入 |  | 0-∞ | 起始 ≤ 结束 |
| 关键词 | 输入框 |  | 空 | 长度 ≤ 50 字符；匹配名称、描述 |
| 显示归档 | 开关 |  | 关 |  |
| 排序 | 单选下拉 | 创建时间 / 更新时间 / 样本数 / 最近使用 / 名称 | 创建时间 |  |
| 排序方向 | 单选 | 升序 / 降序 | 降序 |  |

**交互**：

*   任一筛选/排序变化立即刷新（防抖 300ms）；
    
*   筛选与排序条件保留在 URL 中。
    

#### 4.2 表格列

| 列名 | 说明 | 可排序 | 宽度 |
| --- | --- | --- | --- |
| 复选框 | 多选，用于批量操作 |  | 40px |
| 名称 | 名称 + 版本（灰小字） | ✅（按名称） | 自适应 |
| 样本数 | 数字 | ✅ | 100px |
| 标签 | 彩色标签 | ❌ | 150px |
| 负责人 | 头像 + 用户名 | ❌ | 120px |
| 最近使用 | 相对时间 | ✅ | 120px |
| 状态 | 彩色标签 | ❌ | 90px |
| 创建时间 | 绝对时间 | ✅ | 160px |
| 操作 | "详情" / "更多" 下拉 |  | 120px |

**"更多"下拉内容**（按状态变化）：

*   草稿：编辑 / 发布 / 复制 / 删除
    
*   已发布：编辑（创建新草稿）/ 克隆 / 归档 / 复制
    
*   已归档：查看 / 恢复为草稿（仅平台管理员） / 复制
    

#### 4.3 批量操作

*   仅平台管理员可批量操作；
    
*   多选后浮出操作条（顶部）："批量归档"、"批量删除（仅草稿）"、"批量打标签"；
    
*   批量操作需通过弹窗确认（与单次操作一致），弹窗顶部说明"将对 {N} 个数据集执行此操作"。
    

#### 4.4 列表三态

| 状态 | 展示 |
| --- | --- |
| 加载中 | 骨架屏（表头 + 5 行占位） |
| 空数据 | 图标 + "还没有评估数据集" + "新建你的第一个数据集" 按钮 |
| 加载失败 | 红色文字 "加载失败" + "重试" 按钮 |
| 搜索无结果 | 图标 + "没有符合筛选条件的数据集" + "清空筛选" 按钮 |

#### 4.5 分页

*   默认 20/页，可切 50/100；
    
*   末页时"加载更多"；
    
*   跳转到指定页（输入 1-总页数）；
    
*   底部展示"共 {N} 条 / 第 {M} 页"。
    

#### 4.6 导入

**入口**：列表页右上角"导入"按钮。

**流程**：

1.  下载模板（CSV / JSON 二选一，列说明在模板内）；
    
2.  上传文件（≤ 5MB，校验文件类型与表头）；
    
3.  解析校验（实时显示每行校验结果：✅ / ⚠️ 警告 / ❌ 错误）；
    
4.  选择冲突处理策略：跳过 / 覆盖 / 创建副本（仅针对名称冲突）；
    
5.  确认导入 → 进度条 → 结果汇总（成功 N / 失败 M / 跳过 K）。
    

**校验规则**（与单条创建一致）：必填项、长度限制、JSON 合法等。 **错误处理**：错误行可下载"错误明细文件"（CSV 标注行号与错误原因）。

#### 4.7 导出

**入口**：列表页右上角"导出"按钮。

**弹窗**：

| 字段 | 选项 | 默认 |
| --- | --- | --- |
| 范围 | 当前筛选结果 / 选中项（多选时） | 当前筛选结果 |
| 字段 | 多选：名称/版本/状态/样本数/标签/负责人/最近使用/创建时间/描述 | 全部 |
| 格式 | CSV / Excel | CSV |
| 是否包含样本 | 是/否 | 否 |

**生成**：≤ 1000 行实时生成，> 1000 行异步生成，完成后发站内信并出现在"导出历史"（保留 30 天）。

### 5. 新建/编辑数据集

#### 5.1 数据集元信息表单

**入口**：

*   列表页"新建数据集"按钮；
    
*   列表"更多"菜单 → "编辑"。
    

| 字段 | 必填 | 默认 | 校验规则 | 错误提示 |
| --- | --- | --- | --- | --- |
| 名称 | 是 |  | 长度 1-100；同一负责人下唯一（失焦校验） | "请输入名称（1-100 字）"；"名称已存在" |
| 描述 | 否 |  | 长度 ≤ 500 |  |
| 标签 | 否 | \[\] | 每个标签长度 1-20；最多 10 个 | "标签最多 10 个" |
| 协作成员 | 否 | \[\] | 多选用户，最多 10 人 | "协作成员最多 10 人" |

**按钮**：

*   "保存草稿" — 状态草稿；
    
*   "保存并添加样本" — 保存后跳转到详情页样本 Tab；
    
*   "取消"。
    

#### 5.2 样本编辑表单

**单条样本字段**：

| 字段 | 必填 | 默认 | 校验规则 | 错误提示 |
| --- | --- | --- | --- | --- |
| 自定义 ID | 否 |  | 长度 ≤ 50；同一数据集内唯一 | "自定义 ID 已存在" |
| 输入 | 是 |  | 长度 1-10000 | "请输入测试输入" |
| 上下文 | 否 |  | 长度 ≤ 50000 |  |
| 期望输出 | 否 |  | 长度 ≤ 10000 |  |
| 评分标准 | 是 |  | 长度 10-2000 | "请填写评分标准（10-2000 字）" |
| 关联指标 | 否 | \[\] |  |  |
| 权重 | 否 | 1 | 1-10 整数 | "请输入 1-10 之间的整数" |
| 样本标签 | 否 | \[\] | 每个标签长度 1-20；最多 5 个 | "样本标签最多 5 个" |

**校验**：

*   发布数据集时，样本数 ≥ 1；
    
*   发布数据集时，所有样本的"评分标准"必填。
    

#### 5.3 批量导入样本

**入口**：样本 Tab 顶部"批量导入"按钮。

**弹窗**：

*   文件类型选择：CSV / JSON；
    
*   文件上传（CSV/JSON ≤ 5MB）；
    
*   字段映射预览（前 5 行）；
    
*   "确认导入"按钮。
    

**CSV 字段映射**（默认列名）：

| CSV 列 | 映射到 |
| --- | --- |
| external\_id | 自定义 ID |
| input | 输入 |
| context | 上下文 |
| expected\_output | 期望输出 |
| criteria | 评分标准 |
| rubric\_ids | 关联指标（多个用英文逗号分隔） |
| weight | 权重 |
| case\_tags | 样本标签（多个用英文逗号分隔） |

**JSON 格式**：

```json
[
  {
    "external_id": "case-001",
    "input": "...",
    "context": "...",
    "expected_output": "...",
    "criteria": "...",
    "rubric_ids": [],
    "weight": 1,
    "case_tags": []
  }
]
```

**导入结果**：

*   顶部红色条："成功 {N} 条，失败 {M} 条"；
    
*   失败项可下载错误报告（CSV）；
    
*   成功项直接加入数据集（仅草稿状态可导入）。
