# 产品概述

_本章节详细描述产品的背景、内容和目标等进行详细定义，关于产品定义的其它内容请阅读本产品定义说明书。_

## 产品概述

聚焦员工日常工作任务归集、处理、跟进与闭环管理，解决企业员工工作任务分散、多平台切换、任务状态不同步、待办遗漏遗忘等办公痛点，支持用户自主创建、编辑、管理个人工作待办，并打通钉钉官方待办体系

## 产品范围

可创建待办事项，创建方式包含：手动创建、AI创建、定时任务创建，待办任务查询、处理，可通过天马智擎对话查询待办数据，做待办数据分析

## 产品目标

提供统一的待办归集与处理入口，覆盖手动/AI/定时三种创建方式 打通钉钉待办体系，实现跨平台任务状态同步 通过AI对话能力，支持待办数据的自然语言查询与分析

### 需求编号： <待办中心>

**功能需求描述（业务****简要说明****）**

_一句话描述功能_

统一创建待办任务，支持单条或批量创建待办

**用户角色与用户故事**

_撰写用户故事_

作为普通员工，我希望查看自己的待办任务并处理，以便确保不遗漏任何工作项，按时完成任务。

作为管理角色，我希望给其他人员创建分配待办任务，以便将工作指令快速传达给执行人并跟踪执行进度。

**业务主流程图及说明**

**待办创建流程**：用户发起 → 选择创建方式（手动/AI/定时）→ 填写任务信息 → 保存 → 钉钉通知 → 同步待办中心

**待办处理流程**：查看待办列表 → 筛选/查询 → 查看详情 → 修改状态 → 保存 → 同步钉钉

**业务规则****和约束条件**

1、待办创建方式：手动创建、定时任务创建、AI对话创建，点击AI生成待办跳转到天马智擎，默认填充建待办提示词，AI创建待办任务后同步到待办中心工作台

2、创建待办后发送钉钉待办消息给执行人，在钉钉待办点击去查看跳转到待办中心

3、待办处理状态规则：

待办状态=未完成，可选状态：未完成、已完成

待办状态=已逾期，可选状态：已逾期、已完成

待办状态=已完成，可选状态：判断当前时间与截止时间，当前时间≤截止时间，可选未完成、已完成，当前时间>截止时间，可选已逾期、已完成

**接口说明**

钉钉待办任务通知，待办中心创建待办后同步到钉钉个人待办列表，待办状态变更后也需同步到钉钉
