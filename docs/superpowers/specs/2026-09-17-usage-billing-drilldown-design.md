# 天马智擎用量计费与聊天入口优化设计

## 目标

把现有原型调整为可用于评审的桌面 Web 高保真交互：管理员能从组织逐层下钻至会话，普通用户能查看自己的额度与费用；真实 `/chat` 入口支持专家模式和快捷提示语。

## 管理员用量计费

- 采用树形表格，不使用独立左侧树。
- 固定层级为：部门 → 人员 → 模块 → 子功能 → 会话。
- 首列提供展开箭头、层级缩进、节点类型和子节点数量；支持全部展开、全部收起。
- 顶部支持开始日期、结束日期、部门/人员搜索、额度状态、模式、模块筛选。
- 所有筛选条件修改后立即刷新结果，不保留“应用筛选”按钮；保留一键重置。
- 搜索部门或人员时自动保留并展开命中节点的完整父级路径。
- 删除结算状态及其指标、列、筛选项和详情字段。
- 指标展示人民币消耗、金币消耗、Token、调用次数、当前额度、使用率。
- 额度使用率达到 80% 显示橙色预警，达到 90% 显示红色预警；支持按正常、预警、超限筛选。
- 导出当前筛选范围下的完整层级明细，包含会话级记录。
- 点击会话行打开右侧详情抽屉。

## 普通用户用量计费

- 在头像菜单增加“我的用量”二级入口。
- 普通用户页面不展示管理员设置导航、组织筛选和额度调整操作。
- 首屏突出人民币消耗、当前额度、剩余额度和使用率。
- 明细按模块 → 子功能 → 会话下钻，仅展示当前账号数据。
- 保留日期、模式、模块、额度状态筛选和导出。

## 聊天首页

- 修改实际路由 `/chat` 使用的 `SourceChatHome`，不再把主体验改动放在 `/workspace/chat`。
- 日常办公与专家模式均可在输入框内切换。
- 专家模式展示专家搜索、部门筛选、专家卡片、选中态和专家快捷任务。
- 快捷提示语入口移动到输入框下方、常用卡片上方，并按照“当前模式 + 当前专家”隔离数据。
- 快捷提示语支持搜索、新建、编辑、删除及点击写入输入框。

## 交互与验证

- 关键按钮、筛选、展开、抽屉、菜单、导出均需具备真实可点击反馈。
- 桌面端为主要布局，窄屏保证基本可用。
- 使用组件测试覆盖树形下钻、即时筛选、个人入口、专家模式和快捷提示语位置。
- 最终执行完整测试、类型检查与生产构建，并在运行中的页面验证关键路径。
