# 天马智擎 V1.1.0 交互原型设计

## 目标

在现有 `frontend-mvp` 正式路由中实现 M2、M3、M5、M6、M7 的桌面 Web 高保真可点击原型，不使用未接路由的 `AdminConsoleView.vue`，不新建独立管理后台壳。

## 信息架构

- M2 操作审计日志：`/settings/audit`，超级管理员使用；详情在右侧抽屉打开。
- M3 用量与计费：`/settings/usage`，所有用户可访问；普通用户只查看本人数据，管理员可配置统计层级与筛选对象。
- M5 上下文主动建议：位于正式 `/chat/:sessionId` 最新 AI 回答下方，固定三条；点击后整组消失并直接发送。
- M6 快捷提示语：位于首页和会话输入框工具区；轻量浮层负责搜索、分类和插入，管理抽屉负责增删改。
- M7 会话搜索：升级正式 `/chat` 的搜索弹窗；标题与消息正文混合展示，提供“消息角色”和“对话模式”两个筛选框。

## 视觉语言

沿用正式页面的白底、黑色主操作、zinc 中性色、细边框、弱阴影和 8–14px 圆角。状态只使用语义色，不引入新的品牌色体系。重点适配 1280–1920px 桌面屏幕。

## 关键交互

### M2

- 支持时间范围、操作人花名、对象类型、操作类型、来源和链路编号筛选。
- 导出按钮下载当前筛选结果的演示文件。
- 点击日志行打开右侧抽屉，展示基本信息、变更摘要和变更前后内容。

### M3

- 指标卡同时展示人民币和金币，并包含 Token、有效轮次、调用次数、剩余额度、额度使用率和结算异常。
- 普通用户默认且只能查看本人；管理员可选择统计层级：公司、部门、用户、会话、调用。
- 统计层级和统计对象作为筛选配置，不使用逐层下钻。
- 管理员可打开额度调整弹窗；普通用户不展示该操作。

### M5

- 三条建议仅展示在最新回答下方，不提供开关。
- 点击任一建议后，三条建议同时消失，选中文本作为新用户消息显示。

### M6

- 快捷提示语按分类展示并支持关键词搜索。
- 选择后插入当前光标位置，不自动发送。
- 管理抽屉支持新增、编辑、删除，未分组内容统一归入“未分组”。

### M7

- 标题命中和正文命中混合排序并标注命中类型。
- 筛选框一：全部消息、我发送的、AI 回复。
- 筛选框二：全部模式、日常办公、专家模式。
- 点击正文结果打开会话并携带消息定位参数；目标消息做临时高亮。
- 默认近三个月，可继续加载更早三个月。

## 原型数据边界

全部使用前端模拟数据和本地状态，不接后端接口；筛选、抽屉、弹窗、插入、删除、跳转和高亮均需可点击演示。
