# 日程重叠卡片手风琴交互设计

## 目标

在同一人员、同一时间段存在多场重叠日程时，保证每张日程卡片始终可点击，同时让当前关注的卡片获得足够宽度，以展示标题、时间、会议室、AI 操作和笔记按钮。

## 范围

本次只调整日程看板中同一人员列内的重叠卡片宽度交互，不改变时间轴、冲突判定、状态颜色、人员列排序和笔记弹窗。

## 默认状态

- 同一重叠组内的卡片平均分配人员列宽度。
- 非重叠卡片占满人员列宽度。
- 每张卡片保持三行信息结构：标题、时间范围、会议室（如有）。
- AI 图标和笔记按钮位于标题行右侧。

## Hover 与聚焦状态

- 鼠标进入或键盘聚焦某张重叠卡片时，该卡片固定占重叠组可用宽度的 60%。
- 同组其他卡片平均分配剩余 40%，左右顺序保持不变。
- 卡片不允许相互覆盖，所有卡片始终保留可点击区域。
- 只有当前重叠组重新分配宽度，其他时间段和其他人员列不受影响。
- 当前卡片应完整显示三行信息、AI 图标和笔记按钮；其他卡片继续使用截断文本。

## 最低点击宽度

- 非当前卡片的目标最低宽度为 36px。
- 当固定 60/40 分配会使非当前卡片小于 36px 时，提高人员列的最小宽度。
- 看板沿用现有横向滚动能力，不通过覆盖卡片来弥补宽度不足。

## 状态切换

- 鼠标进入新卡片时，立即把该卡片设为当前卡片。
- 鼠标离开重叠组后延迟 120ms 恢复平均分配，减少边界抖动。
- 在延迟期间进入同组另一张卡片，应取消恢复并直接切换当前卡片。
- 点击 AI 或笔记按钮时保持当前卡片展开。
- 键盘聚焦执行与 Hover 相同的宽度分配；按 Escape 或焦点离开重叠组后恢复默认状态。

## 宽度计算

设重叠组卡片数量为 `n`：

- 默认状态：每张卡片宽度为 `100% / n`。
- 展开状态：当前卡片宽度固定为 `60%`。
- 其余每张卡片宽度为 `40% / (n - 1)`。
- 左侧位置按照卡片原有顺序，累加前序卡片的当前宽度计算。

示例：

- 2 场：`60% / 40%`
- 3 场：`60% / 20% / 20%`
- 4 场：`60% / 13.33% / 13.33% / 13.33%`

## 动效与可访问性

- 宽度与水平位置使用 160ms 缓动过渡。
- 系统启用“减少动态效果”时关闭过渡动画。
- 重叠卡片保留键盘焦点入口和明确的焦点样式。
- 宽度变化不能改变日程的时间位置和卡片高度。

## 验收与测试

- 验证 2、3、4 场重叠时当前卡片均固定占 60%。
- 验证其他卡片平均分配剩余 40%，总宽度为 100%，且没有覆盖。
- 验证从中间卡片切换到两侧卡片时顺序不变、鼠标目标不丢失。
- 验证展开后 AI 与笔记按钮可点击。
- 验证鼠标离开、焦点离开和 Escape 均恢复默认宽度。
- 验证最低 36px 点击宽度以及人员列扩宽后的横向滚动。
- 验证非重叠卡片、其他人员列和状态颜色不受影响。
