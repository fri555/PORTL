# 工作台 C1+ AI/MCP 改版设计

日期：2026-07-20

## 背景

工作台从原先的系统入口型页面，升级为个人工作驾驶舱。目标不是复刻钉钉 ONE，也不是做管理者监控台，而是帮助用户每天快速判断：

- 我错过了什么重要消息？
- 今天有哪些日程和待处理事项？
- 我要进入哪个系统？
- 能否用 AI 一句话预填日程或待办，并在确认后同步到钉钉？

本期是 `frontend-mvp` 高保真交互原型，数据仍使用 mock。交互和信息架构需要对齐后续钉钉 MCP/Skill 接入路径。

## 产品原则

1. 用户控制优先：AI 只做摘要、解析、预填和建议，不直接产生外部副作用。
2. 创建必须确认：AI 一句话创建日程或待办时，必须打开确认面板，用户点击确认后才调用钉钉 MCP。
3. 不做管理监控：消息摘要、待办聚合和日程看板以当前用户个人工作减负为目标，不展示员工排行、已读压力或越权状态。
4. 保留业务对象边界：消息、日程、审批、任务、系统入口保持独立对象，不做混杂信息流。
5. MVP 收敛范围：本期不做发起审批表单，只聚合审批查询与处理入口。

## 页面布局

采用 C1+ 布局：

1. 顶部同一卡片行：左侧为聚合概览，右侧为简洁 AI 对话框。
2. 下方左列：上方消息摘要，下方系统入口。
3. 下方右列：工作处理大卡，内部包含日程看板和待办中心。

顶部聚合概览和 AI 对话框属于同一视觉卡片区域，不做一整条指标墙。聚合概览只展示三个核心指标：

- 未读消息
- 待处理事项
- 今日日程

不在顶部展示：

- 冲突提醒：放回日程看板内部。
- 常用系统数量：放回系统入口模块内部。

## 模块设计

### 今日工作概览

展示当天核心工作压力：

- 未读消息总数，以及高优先未读数量。
- 待处理事项总数，拆分审批和任务。
- 今日日程数量，以及下一场会议时间。

概览用于快速判断工作压力，不承载具体操作流。点击指标可在下方对应模块中筛选定位。

### AI 工作助手

顶部右侧放一个简洁对话框，不做复杂聊天页面。

能力：

- 查询：例如“总结我的未读消息”“今天有什么待处理”。
- 搜索：搜索日程、审批、任务或系统。
- 一句话创建：例如“明天 10 点约张总开需求评审，并提前 15 分钟提醒”。

MVP 行为：

- 展示输入框、快捷建议和 mock 响应。
- 一句话创建时打开创建面板并预填字段。

后续 MCP 行为：

1. AI 解析用户输入。
2. 判断创建类型：日程或待办。
3. 打开大面积创建面板。
4. 预填标题、时间、参与人、提醒、执行人、优先级等字段。
5. 用户检查并点击确认。
6. 调用钉钉日历 MCP 或钉钉待办 MCP 创建。

禁止行为：

- 不允许 AI 解析后直接创建。
- 不允许未确认就同步钉钉。
- 不允许自动发送消息。

### 消息摘要

位置：下方左列上半部分。

目标：回答“我错过了什么重要消息？”

展示内容：

- 今日重要未读 TOP。
- 单聊、@我、高管或上级消息优先。
- 群聊内容摘要。
- AI 摘要理由，例如“单聊 + @我 + 高优先发送人”。
- 待回复事项。

操作：

- 去钉钉查看。
- 稍后处理。
- 降低优先级。
- 自定义规则入口。

真实接入方向：

- 未读消息总结 Skill。
- 群聊消息摘要 Skill。
- 通讯录 MCP 用于角色、主管、职级和关注人判断。
- 需要依赖 MCP 配置和 dws 能力读取未读消息，不由纯前端直接完成。

### 系统入口

位置：下方左列下半部分。

目标：回答“我要快速进入哪个系统？”

功能：

- 常用 / 全部两个标签。
- 系统名称左右模糊搜索。
- 加入常用 / 取消常用。
- hover 提示“加入常用”或“取消常用”。
- 上传 Logo，MVP 仅本地预览。
- 固定高度，系统数量过多时内部滚动。

系统卡片信息保持简洁：

- 图标
- 系统名称
- 架构标签
- 常用星标

### 工作处理

位置：下方右列大卡。

目标：回答“今天我要处理什么？”

顶部采用混合式搜索/命令入口：

- 搜索框：MVP 做日程、审批、任务搜索。
- 文案预埋命令能力，例如“搜索日程/审批/任务，或输入‘明天 10 点约张总开评审’”。
- `＋ 新建`：打开大面积创建面板。
- 筛选：全部 / 日程 / 审批 / 任务。

工作处理内部拆成两个独立区域：

1. 日程看板
2. 待办中心

因为顶部已经有统一搜索和创建，日程看板与待办中心可以视觉上分开，避免过度融合。

### 日程看板

功能：

- 今日日程和本周日程。
- 日历可收起。
- 高管日程展示。
- 冲突标红。
- 搜索结果联动。
- 点击日程可查看详情。

后续 MCP：

- 钉钉日历 MCP：创建日程、查询日程、查询闲忙、建议时间、会议室查询。
- 高管日程需要授权和组织可见性控制。

### 待办中心

待办中心包含审批与任务，但不包含会议。

审批分组：

- 待处理
- 已处理
- 我发起的
- 抄送我的

任务 / 待办分组：

- 待处理
- 已处理
- 我负责的
- 我创建的

展示信息：

- 标题
- 类型：审批或任务
- 优先级
- 截止时间
- 来源
- 负责人或发起人
- 状态

操作：

- 搜索。
- 查看详情。
- 完成任务。
- 跳转钉钉处理审批。

后续 MCP：

- 钉钉待办 MCP：创建待办、查询待办、更新完成状态。
- 钉钉 OA 审批 MCP：查询待处理、已处理、我发起、抄送我，处理审批可后续谨慎开放。

## 新建面板

点击 `＋ 新建` 或 AI 一句话创建后，打开大面积侧栏式创建面板。

本期只支持：

- 新建日程
- 新建待办

本期不支持：

- 发起审批

原因：审批模板多、字段差异大、流程权限复杂。发起审批应作为后续审批中心能力，不纳入工作台 MVP。

### 新建日程字段

- 标题
- 开始日期与时间
- 结束日期与时间
- 时区
- 是否全天
- 重复规则
- 参与人
- 地点
- 会议室
- 视频会议
- 正文 / 议题 / 附件
- 日历归属
- 忙闲状态
- 提醒时间
- 组织归属
- 时间轴预览
- 冲突提示

### 新建待办字段

- 标题
- 描述
- 执行人
- 截止日期，含今天、明天、其他日期快捷项
- 优先级
- 标签
- 附件
- 参与人
- 组织归属

### AI 一句话创建确认规则

AI 一句话创建必须经过：

1. 用户输入自然语言。
2. AI 解析意图和字段。
3. 打开创建面板。
4. 预填字段。
5. 用户确认。
6. 执行创建。

异常处理：

- 时间不明确：提示补充时间。
- 参与人匹配多个：要求用户选择。
- 参与人不存在：标记字段错误。
- 日程冲突：标红提示，但允许用户确认。
- 待办缺少执行人：阻止创建。
- 用户取消：不产生外部副作用。

## MVP 实现范围

本次前端原型实现：

- C1+ 页面布局。
- 顶部概览 + 简洁 AI 工作助手。
- 消息摘要 mock 卡片。
- 系统入口保留当前常用、全部、搜索、上传 Logo、星标功能。
- 工作处理大卡。
- 日程看板 mock。
- 待办中心 mock，含审批与任务分组。
- `＋ 新建` 大面积面板。
- AI 一句话创建 mock：预填表单，不真实创建。

不实现：

- 真实钉钉 MCP 调用。
- 发起审批表单。
- 自动回复消息。
- 自动创建日程或待办。
- 管理者监控或已读统计。

## 测试与验证

前端验证：

- 页面能在本地开发服务器打开。
- 工作台布局在常规桌面宽度下不溢出。
- 系统入口固定高度，内部滚动。
- 消息摘要、工作处理和概览数据正确展示。
- 搜索输入能过滤 mock 项。
- `＋ 新建` 打开面板。
- 日程/待办切换正常。
- AI 一句话输入能打开预填确认面板。
- 取消不会改变 mock 数据。
- 确认创建只更新本地 mock 数据或展示成功状态。

自动化验证：

- 运行相关单测。
- 运行 typecheck。
- 运行 production build。
