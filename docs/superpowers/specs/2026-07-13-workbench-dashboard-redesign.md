# 工作台仪表盘改版设计规格

日期：2026-07-13

## 目标

在不改动现有全局顶部导航的前提下，重构 `frontend-mvp` 的 `/portals` 工作台内容区。页面参考用户提供的企业工作台截图，形成“系统入口 + 日历 + 今日日程 + 待办事项”的高保真可交互布局。

## 页面结构

- 页面顶部展示问候语、工作提示、天气摘要和当前日期。
- 主体采用左右双栏布局，桌面端为 60:40，系统入口为主区域。
- 左栏为系统入口卡片，使用 3 列矩阵并保留搜索与分类筛选能力。
- 右栏上半部分拆为日历与今日日程两栏。
- 右栏下半部分为待办事项列表。
- 不修改 `AppHeader` 的现有品牌、知识中心、工作台、AI 治理及用户菜单。

## 系统入口

- 展示用户提供的 11 个企业系统入口，包含名称、简述、图标与方向提示：AI大模型、天马运动、大库存、售后工单、内容中心、需求管理系统、新运营、【自营】订单系统、第三方系统、新零售、耶运动-视觉内容中心。
- 使用蓝、橙、青、红、紫等低饱和浅色背景区分系统类别。
- 点击系统入口沿用现有单点登录/外链逻辑。
- 提供搜索入口；无匹配结果时显示明确空状态和清空入口。
- 底部显示“查看全部系统”操作及系统总数。

## 日历

- 默认展示当前月份的完整月视图。
- 支持上月、下月和“今天”操作。
- 点击日期后以蓝色圆形高亮选中日；日程区同步显示对应日期标题。
- 周标题和非当前月日期使用弱化颜色。

## 今日日程

- 展示时间范围、标题、地点和状态。
- 状态包括进行中、即将开始、未开始，分别使用蓝、绿色和灰色文字。
- 使用左侧时间轴表达日程顺序。
- 无日程日期展示空状态。

## 待办事项

- 提供“全部、我负责的、我参与的”三个筛选标签及数量。
- 每项展示复选框、任务名称和截止时间。
- 点击复选框可切换完成状态，完成项使用删除线与弱化色。
- 临近截止或已逾期任务使用橙色/红色时间提示。
- 提供“查看全部待办”操作。

## 响应式与交互

- 大屏为双栏；中屏先保留系统入口与右侧工作区；窄屏改为单列。
- 窄屏顺序：问候摘要、系统入口、日历、日程、待办。
- 所有按钮具备可见焦点和语义化标签。
- 动效只用于卡片悬浮、月份切换和待办完成状态，并遵守减少动态效果偏好。

## 导航问题

- 当前路由配置有效，知识中心和工作台入口本身没有被治理页改坏。
- 导航失效由开发服务退出后，浏览器无法加载懒加载页面模块导致。
- 实现完成后重新启动 Vite 服务，并通过路由回归测试验证 `/knowledge` 与 `/portals` 可解析。

## 验收标准

- 顶部全局导航视觉和结构保持不变。
- 工作台桌面布局与参考截图的信息结构一致。
- 系统搜索、月份切换、日期选择、待办筛选和完成切换均可操作。
- `/knowledge`、`/portals` 和 `/admin/governance` 路由均可正常解析。
- 聚焦测试和生产构建通过；全量测试中的既有失败需单独记录。
