# 首页组件复刻规格

## 视觉基线

- 页面使用线上系统字体栈、白色主画布和浅灰左侧任务栏；主内容桌面端约 800px 宽并水平居中。
- 顶部标语为“职场超能力，耶虎让你快人一步”，标语下方是 206×38、圆角 24px 的双模式胶囊；日常办公/业务专家点击立即切换。
- 输入框约 800px 宽、150px 高、16px 圆角；底部从左到右为附件、联网查询和发送。保留现有可交互状态。
- 快捷提示语入口必须位于输入框下、业务卡片上，并继续按日常办公/具体专家隔离数据；这是本地在生产基线上的增强能力。
- “快捷开始”标题为 14px 灰色。日常办公为三列卡片，单卡约 258×74、16px 圆角、浅边框；补齐线上“查商品”卡片并标注 NEW。
- 业务专家模式在输入框下显示：全部、通用、商品、直播、B2B、B2C、门店。保留搜索专家，并匹配线上紧凑三列专家卡。
- 专家选择后保留当前的已选专家摘要、快捷入口和发送路由，不破坏既有功能。

## 行为

- 模式切换立即生效并清理上一个模式的筛选/已选专家。
- 日常卡片点击把完整提示词写入输入框并聚焦。
- 分类与搜索组合过滤；清空筛选可恢复全部。
- 快捷提示语管理可打开、增删改并插入当前光标位置。
- Enter 发送、Shift+Enter 换行；专家模式未选择专家时禁止发送。

## 验证点

- `source-chat-home`、`hero-composer`、`quick-prompt-entry`、日常卡、专家卡测试标识保持可用。
- 测试覆盖双模式切换、快捷提示语位置/隔离、日常卡填充、专家筛选和选择。
