# 设置页组件复刻规格

## 视觉基线

- 线上设置页为浅灰页面底，内容白色卡片距外框约 8px，圆角约 8px、细边框；内容顶部与全局导航衔接。
- 标题区左侧 18px“智能体管理”，右侧搜索与黑色主按钮。
- 筛选行使用紧凑下拉/输入控件，含清空与查询；列表表头浅灰，行高约 56px，状态开关黑色，末列省略菜单。
- 默认进入智能体管理时优先呈现线上同款列表密度，不展示抢占注意力的大号统计卡。
- 其他设置子页沿用同一壳层、标题、筛选和列表视觉，确保切换时不跳变。

## 必须保留的本地增强

- 保留额度、模型、工具、智能体的全部增删改查交互。
- 保留审计日志与“用量计费”；用量计费仍支持部门→人员→模块→子功能→会话下钻、立即筛选、时间范围、预警和导出。
- 员工头像菜单中的“我的用量”及个人视图保持不变。
- 不引入线上不存在的“结算状态”。

## 验证点

- 测试覆盖设置导航、搜索/筛选、清空/查询、新建、状态切换和菜单。
- 确认用量计费原有测试继续通过，桌面端主表不产生横向遮挡。
