# 知识中心上传文件弹窗复刻规格

## 视觉基线

- 弹窗桌面端约 740px 宽、最大高度接近视口，24px 圆角；遮罩为约 40% 黑色。
- 顶部标题“上传文件”和关闭按钮，高度约 58px。
- 第一行必须是必填“上传至”选择器，占满剩余宽度，提示“请选择知识库或文件夹”。
- 上传区约 150px 高，支持点击、拖拽、粘贴；明确展示：pdf、doc、docx、xls、xlsx、csv、txt、md；单文件不超过 50MB；最多 100 个。
- 文件区在空状态显示“暂无本地文件”“请在上方点击、拖拽或粘贴文件”；桌面端文件区约 400px 高，保持弹窗底部按钮稳定。
- 底部右对齐“取消”“确定”；没有目标或文件时确定按钮禁用。

## 行为与增强

- 目的地可选择知识库或文件夹；若从具体目录发起则默认选中当前目录。
- 文件选择、拖拽与粘贴统一校验扩展名、大小、数量；错误就地提示，不静默失败。
- 已选文件显示名称、大小、校验状态，可逐个移除；重复文件去重。
- 确认后沿用现有上传事件与任务中心，不修改权限、重命名等其他弹窗行为。

## 验证点

- 新增/更新测试覆盖目的地必填、空状态、拖拽/选择、删除文件、非法文件和确认禁用状态。
