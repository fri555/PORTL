# Page topology

## `/chat`

- Global header
- 270 px conversation sidebar
  - search / collapse
  - new conversation
  - task files
  - daily histories and expert histories
  - per-session secondary menu: rename, share, delete
- Main landing
  - source mascot/slogan
  - composer
  - mode popover
  - daily quick actions or expert grid

## `/chat/:sessionId`

- Same sidebar
- Conversation log
- Answer anchor rail
- Task-file drawer trigger
- Fixed compact composer
- Optional bottom share bar

## `/files`

- Same sidebar
- Searchable grouped file table
- Expanded child rows
- Right preview drawer

## `/knowledge` permission states

- Permission manager dialog
- Per-member remove popover
- Add-member organization picker dialog
