# SourceChatSidebar

- Width: 270 px desktop, white, right hairline border.
- Header actions: search and collapse with tooltips.
- Primary black `新对话` button and `任务文件` navigation row.
- Daily and expert sections use captured titles/timestamps and 40 px real avatars.
- Clicking a session emits navigation; more button opens rename/share/delete popover.
- Active session uses source light-gray selected fill.
