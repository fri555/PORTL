# SourceChatDetail

- Scrollable conversation log with user prompt, assistant identity, thinking-time status, structured headings/tables, and completion status.
- Message actions: copy, reference, share.
- Right answer-anchor rail and `展开任务文件` control.
- Fixed compact composer; expert sessions use expert-specific placeholder.
- Share state renders a bottom bar with `复制链接`, `发送到钉钉`, and close.
