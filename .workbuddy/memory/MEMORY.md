# 项目长期记忆（MEMORY.md）

## 自研企业级 Agent 平台（额度管控 / 内部金币体系）
- 目标：将 Agent 平台资源消耗与企业内部「金币」(虚拟积分) 挂钩，做成本控制 + 内部市场化结算。
- 计划底座：**DeepSeek V4**（性价比锚点，永久 2.5 折；7月中旬正式版引入峰谷定价，高峰9-12/14-18点 ×2）+ **阿里百炼 Model Studio**（国产模型、数据不出境、有SLA）。
- ⚠️ 选型红线：阿里百炼 **Token Plan 团队版不可用于后端自动化/应用后端**（仅限交互式工具），自研后端多租户平台必须走百炼「按量付费/资源包/节省计划」接入。
- 设计共识（行业对齐）：统一 Credits 抽象层(0.01-0.05元/积分) + 三级配额(企业→部门→个人) + 共享池+个人独占配额 + 超额三模式(自动扣款/拦截/等待重置) + 工程层(令牌桶多时间窗+成本熔断+429透明响应)。
- **金币体系约束(用户明确锁定)**：金币是既有内部体系(可换奖品)，**10金币=1元比例固定不可动**；消耗金币**四舍五入取整**(保留1位小数、单次最低0.1)；抵扣优先级=每日赠送额度(优先)→[后续]金币兑换token；**MVP限额只到用户个人层级**(每日+可选月度)，企业/部门/项目分层与共享池为后续阶段。
- 金币建议基线：10金币=1元(固定)、每日赠50金币当量/人(≈¥150/人/月)、单任务硬上限500金币、扣减=实际token×实时单价(感知峰谷)×难度乘数(非固定系数)→四舍五入(最低0.1)。
